# MAX98357A 功放

## 一句话理解

MAX98357A 是一颗**I2S 输入的 Class-D 功放芯片**——你把 [[i2s-protocol-I2S协议|I2S 数字音频灌进去]]，它直接输出足够驱动扬声器的功率。不需要外部 DAC，不需要 MCLK，简单到 3 根信号线就能响。

## 为什么学它

reGlasses 有 2 颗 MAX98357A (U16 左声道 + U17 右声道)，驱动双扬声器。所有提示音、语音反馈、TTS 播报都从这里出声。

## 硬件连接

```
WQ7036AX (I2S Master)           MAX98357A U16 (左)    MAX98357A U17 (右)
  AMP_I2S_BCLK ─── R163 ─────→ BCLK (C1)           → BCLK (C1)
  AMP_I2S_LRCLK ─── R167 ────→ LRCLK (C3)          → LRCLK (C3)
  AMP_I2S_DOUT ──── R170 ────→ DIN (B1)            → DIN (B1)
  AMP_SD_MODE ───── R161 ────→ SD (使能/关断)       → SD
  VDD_AMP_3V3 ───────────────→ VDD (A2)            → VDD
                                    │                    │
                              AMP1_OUTP/N          AMP2_OUTP/N
                                    │                    │
                                左扬声器              右扬声器
```

## 关键特性

| 特性 | 说明 |
|------|------|
| I2S 输入 | 不需要 MCLK！内部有时钟恢复 |
| Class-D | 效率 >90%，不发烫 |
| 功率 | 2.5W (4Ω, 5V 供电) |
| 声道选择 | LRCK 高 = 左 (U16)，低 = 右 (U17) |
| 封装 | WLP 1.347×1.437mm (极小) |

## 声道选择原理

两颗 MAX98357A **共享同一条 I2S 总线**，怎么区分左右？

```
LRCK: ┌──────┐         ┌──────┐
       │ HIGH │         │ HIGH │   ← 高电平 = 左声道数据
  ─────┘      └─────────┘      └───

DATA: [L15 L14 ... L0] [R15 R14 ... R0] [L15 ...]
       ↑ 只有 U16 接收   ↑ 只有 U17 接收
```

MAX98357A 内部有个"门"：LRCK 高电平时打开左声道接收，低电平时打开右声道接收。U16 被配置为只接收左声道，U17 只接收右声道。

## SD_MODE (使能控制)

WQ7036AX 的 GPIO (B13) 通过 R161 连接到 SD (Shutdown) 引脚：

| SD 电平 | 状态 | 功耗 |
|---------|------|------|
| 高 | 正常工作 | ~数 mA |
| 低 | Shutdown (关断) | ~μA |

不需要播放声音时，拉低 SD 省电。

问：MAX98357A 需要 MCLK 吗？
答：不需要。内部有时钟恢复电路，只需 BCLK 和 LRCK 即可从 I2S 数据中恢复时钟。

问：reGlasses 的两颗 MAX98357A 如何区分左右声道？
答：共享同一条 I2S 总线。LRCK 高电平时 U16 (左) 接收数据，低电平时 U17 (右) 接收数据。
