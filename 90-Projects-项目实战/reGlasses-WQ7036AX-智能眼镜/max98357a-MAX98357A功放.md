# MAX98357A 功放

**一句话结论**：MAX98357A 是一颗 I2S 输入的 Class-D 音频功放芯片——你把 I2S 数字音频灌进去，它直接输出足够驱动扬声器的功率。不需要外部 DAC，不需要 MCLK，3 根信号线（BCLK/LRCLK/DIN）就能工作。

---

## 30 秒先看懂

- reGlasses 使用 2 颗 MAX98357A（U16 左声道 + U17 右声道）驱动双扬声器。
- 两颗功放共享同一条 I2S 总线，通过 LRCK 电平区分左右声道（高电平 = 左声道数据，低电平 = 右声道数据）。
- SD_MODE 引脚控制使能/关断：高电平工作，低电平 Shutdown 省电（uA 级功耗）。
- 内部有时钟恢复电路，不需要 MCLK 信号，简化了硬件设计。
- 在 SDK 中搜索 `CONFIG_DRIVER_I2S_EXT_PA_ENABLE` 确认外部功放已启用。

| 中文 | 英文 | 具体含义 |

## 第一层：费曼心智模型

### 类比：一套音响系统中的两个喇叭

MAX98357A 就像一套音响系统中的两个独立功放：

| 组件 | 类比 | 说明 |
|------|------|------|
| WQ7036AX I2S Master | CD 播放器 | 输出数字音频信号 |
| MAX98357A U16（左） | 左声道功放 | 只接收左声道数据，驱动左扬声器 |
| MAX98357A U17（右） | 右声道功放 | 只接收右声道数据，驱动右扬声器 |
| SD_MODE | 电源开关 | 听音乐时打开，不听时关闭省电 |

**为什么不需要 MCLK？** 传统 I2S 功放需要主时钟 MCLK 用于内部 DAC 的时钟参考。MAX98357A 内部有时钟恢复电路，直接从 BCLK 和 LRCLK 中提取时钟，简化了硬件设计。

### 边界

- MAX98357A 只接收 I2S 数字音频输入，不能接收模拟音频输入。
- 功放输出功率受供电电压和扬声器阻抗限制（2.5W @ 4ohm, 5V）。
- 两颗功放共享 I2S 总线，通过 LRCLK 电平区分声道，所以必须同时工作，不能单独控制某一声道。

### 场景推演

**场景：手机播放音乐，眼镜扬声器出声**

1. 手机通过 A2DP 经典蓝牙发送音乐流到 WQ7036AX
2. WQ7036AX 解码音频（SBC/AAC）→ PCM 数据
3. PCM 数据送入 I2S 控制器，生成 I2S 时序：BCLK、LRCLK、DIN
4. 两颗 MAX98357A 同时收到 I2S 信号
5. LRCLK 高电平时，U16（左）接收 DIN 上的数据
6. LRCLK 低电平时，U17（右）接收 DIN 上的数据
7. 功放内部放大信号，驱动扬声器发出声音
8. 用户暂停音乐时，WQ7036AX 拉低 SD_MODE，功放进入 Shutdown 省电

## 第二层：原理、时序与约束

### 硬件连接

```
WQ7036AX (I2S Master)           MAX98357A U16 (左)    MAX98357A U17 (右)
  AMP_I2S_BCLK ─── R163 ─────→ BCLK (C1)           → BCLK (C1)
  AMP_I2S_LRCLK ─── R167 ────→ LRCLK (C3)          → LRCLK (C3)
  AMP_I2S_DOUT ──── R170 ────→ DIN (B1)            → DIN (B1)
  AMP_SD_MODE ───── R161 ────→ SD (使能/关断)       → SD
  VDD_AMP_3V3 ───────────────→ VDD (A2)            → VDD
                                    │                    │
                              AMP1_OUTP/N          AMP2_OUTP/N
                                    │                    │
                                左扬声器              右扬声器
```

### 关键特性

| 特性 | 说明 |
|------|------|
| I2S 输入 | 不需要 MCLK！内部有时钟恢复 |
| Class-D | 效率 >90%，不发烫 |
| 功率 | 2.5W (4Ω, 5V 供电) |
| 声道选择 | LRCK 高 = 左 (U16)，低 = 右 (U17) |
| 封装 | WLP 1.347x1.437mm (极小) |

### 声道选择原理

两颗 MAX98357A 共享同一条 I2S 总线，通过 LRCLK 电平区分左右声道：

```
LRCK: ┌──────┐         ┌──────┐
       │ HIGH │         │ HIGH │   ← 高电平 = 左声道数据
  ─────┘      └─────────┘      └───

DATA: [L15 L14 ... L0] [R15 R14 ... R0] [L15 ...]
       ↑ 只有 U16 接收   ↑ 只有 U17 接收
```

MAX98357A 内部有个"门"：LRCK 高电平时打开左声道接收，低电平时打开右声道接收。U16 被配置为只接收左声道，U17 只接收右声道。

### SD_MODE（使能控制）

WQ7036AX 的 GPIO（B13）通过 R161 连接到 SD（Shutdown）引脚：

| SD 电平 | 状态 | 功耗 |
|---------|------|------|
| 高 | 正常工作 | ~数 mA |
| 低 | Shutdown（关断） | ~μA |

不需要播放声音时，拉低 SD 省电。

## 第三层：真实 SDK 代码

### 配置文件

**文件路径**：`defconfig.stereo.i2s`

```c
CONFIG_DRIVER_I2S_EXT_PA_ENABLE=y   // 外部功放 (MAX98357A)
CONFIG_DUAL_SPK_ENABLE=y            // 双扬声器使能
```

### 音频播放 API

**文件路径**：`wq-adk/components/audio_service/api/aud_sv_api.h`

```c
// 播放 PCM 音频
aud_sv_play_pcm(data, len, sample_rate);
```

该函数内部会：
1. 将 PCM 数据送入 I2S 控制器
2. I2S 控制器生成 BCLK/LRCLK/DIN 时序
3. MAX98357A 接收并放大信号
4. 扬声器发声

### 功放使能控制

在启动时拉高 SD_MODE 引脚，使能功放：
```c
// 伪代码：使能功放
gpio_set_level(AMP_SD_MODE_PIN, 1);
```

在进入低功耗模式时拉低 SD_MODE：
```c
// 伪代码：关断功放省电
gpio_set_level(AMP_SD_MODE_PIN, 0);
```

## 第四层：正常与异常路径

### 正常路径

系统启动 → 拉高 SD_MODE → 配置 I2S 控制器 → 音频数据送入 I2S → MAX98357A 放大 → 扬声器出声 → 停止播放 → 拉低 SD_MODE 省电

### 异常路径

| 问题 | 现象 | 根因 |
|------|------|------|
| 无声音输出 | 扬声器不响 | SD_MODE 拉低（功放处于 Shutdown）或 I2S 无时钟输出 |
| 声音失真/破音 | 扬声器发出噼啪声 | I2S 位深/声道数配置不匹配，或音量过大导致削波 |
| 左右声道反 | 立体声左右互换 | I2S LRCLK 极性配置错误 |
| 声音小 | 扬声器音量不足 | 功放供电电压不足或扬声器阻抗不匹配 |
| 单声道有声音 | 只有一边响 | 某一路 MAX98357A 损坏或连接异常 |
| 噪声 | 有背景嘶嘶声 | I2S 时钟抖动或电源噪声耦合 |

## 第五层：调试方法

### 1. 检查 I2S 输出波形

用示波器或逻辑分析仪抓取 AMP_I2S_BCLK、AMP_I2S_LRCLK、AMP_I2S_DOUT 引脚：
- BCLK 应有稳定的时钟信号
- LRCLK 频率应为采样率（如 16kHz 音频 => LRCLK=16kHz）
- DIN 应有数据跳变（播放时）

### 2. 检查 SD_MODE 电平

万用表测量 AMP_SD_MODE 引脚电压：
- 播放时：应为高电平（~3.3V）
- 停止时：应为低电平（~0V）

### 3. 检查供电

万用表测量 VDD_AMP_3V3 引脚电压，确认供电正常（3.3V）。

### 4. 确认 I2S 配置

检查 Kconfig 中 `CONFIG_EXT_TRANS_I2S_SAMPLE_RATE` 是否正确配置为 16000（16kHz 音频）。

### 5. 声道测试

播放测试音频，分别验证左右声道输出是否正常：
- 播放左声道测试音 → 只有 U16 对应的扬声器响
- 播放右声道测试音 → 只有 U17 对应的扬声器响
