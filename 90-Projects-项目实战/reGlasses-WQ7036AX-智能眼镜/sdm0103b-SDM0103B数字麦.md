# SDM0103B 数字麦

**一句话结论**：SDM0103B 是一颗 PDM 接口的 MEMS 数字麦克风——声波振动内部的微型振膜，芯片直接输出 1-bit PDM 数字信号，不需要外部 ADC。reGlasses 使用 4 颗组成麦克风阵列，是所有音频功能的起点。

---

## 30 秒先看懂

- 4 颗 SDM0103B 分成两组：左声道组（U12+U13，MIC_BIAS_0 供电）和右声道组（U14+U15，MIC_BIAS_1 供电）。
- 每组两颗麦共享同一条 DATA 线，通过 L/R 引脚电平区分：L/R=GND 的麦在 CLK 上升沿输出，L/R=VDD 的麦在下降沿输出。
- 每颗麦需要 3 根线：CLK（时钟，由 WQ7036AX 提供）、DATA（数据输出）、L/R（声道选择）。
- 供电由 WQ7036AX 的 MIC_BIAS 引脚提供（偏置电压 1.6-3.6V），CLK 频率 2.048MHz。
- 数据流：声波 → 振膜 → Sigma-Delta 调制器 → PDM 1-bit 输出 → WQ7036AX PDM Controller → Decimation Filter → PCM 16-bit。

## 第一层：费曼心智模型

### 类比：四个录音师在会议室里

SDM0103B 就像四个录音师在会议室的不同位置录音：

| 麦克风 | 位置 | 类比 |
|--------|------|------|
| U12 | 左前 | 位于会议室左前方的录音师 |
| U13 | 左后 | 位于会议室左后方的录音师 |
| U14 | 右前 | 位于会议室右前方的录音师 |
| U15 | 右后 | 位于会议室右后方的录音师 |

**为什么需要 4 颗？** 因为单颗麦只能采集声音强度，无法判断声音来自哪个方向。4 颗麦组成阵列，通过波束成形算法可以增强特定方向的声音（如用户说话的方向），同时抑制其他方向的噪声。

**L/R 区分原理**：就像两个人共用一条电话线，约定一人单数日打、另一人双数日打。同样，两颗麦共用一条 DATA 线，一颗在 CLK 上升沿输出，另一颗在下降沿输出，互不干扰。

### 边界

- SDM0103B 是数字麦克风，输出的是 PDM 1-bit 数字信号，不是模拟信号。
- 每颗麦需要 3 根线（CLK、DATA、L/R），但 4 颗麦总共只需要 2 条 DATA 线（每组一条）。
- 麦克风阵列需要 WQ7036AX 的 PDM Controller 硬件支持，不是所有 MCU 都有这个外设。

### 场景推演

**场景：用户在嘈杂街头说"接听电话"**

1. 用户的声音和街上的噪声同时传入 4 颗麦克风
2. 每颗麦的振膜振动，Sigma-Delta 调制器输出 PDM 1-bit 流
3. 通过 CLK+DATA 线送入 WQ7036AX PDM Controller
4. Decimation Filter 将 4 路 PDM 转换为 4 路 PCM 16-bit
5. PCM 数据送入 DCORE 做波束成形，增强用户方向的声音
6. 同时 NR 降噪去除背景噪声
7. VAD 检测到"接听电话"的语音
8. 语音经过 Opus 编码发送到手机，手机识别并执行接听操作

## 第二层：原理、时序与约束

### 阵列布局

```
        ┌──── 眼镜正面 ────┐
        │                  │
   U12  │   [TOF]  [广角]  │  U14
  (左前) │                  │ (右前)
        │                  │
   U13  │                  │  U15
  (左后) │                  │ (右后)
        └──────────────────┘

左声道组 (L1):  U12 + U13, 供电 MIC_BIAS_0 (WQ7036AX B5)
右声道组 (R1):  U14 + U15, 供电 MIC_BIAS_1 (WQ7036AX A7)
```

### 连线详情

```
左声道组:
  DMIC_L1_CLK ──FB5──→ U12.CLK     U12.DATA ─┐
  DMIC_L1_CLK ──FB4──→ U13.CLK     U13.DATA ─┤── FB3 ──→ WQ7036AX
                                              L/R 引脚区分前/后

右声道组:
  DMIC_R1_CLK ──FB8──→ U14.CLK     U14.DATA ─┐
  DMIC_R1_CLK ──FB9──→ U15.CLK     U15.DATA ─┤── FB2 ──→ WQ7036AX
                                              L/R 引脚区分前/后
```

FB（Ferrite Bead，磁珠）的作用：滤除高频噪声，防止数字信号干扰音频。

### L/R 选择

每组的 2 颗麦通过 L/R 引脚电平区分：
- L/R = GND → 数据在 CLK 上升沿输出（前：U12、U14）
- L/R = VDD → 数据在 CLK 下降沿输出（后：U13、U15）

```
CLK:   ╱╲╱╲╱╲╱╲
        ↑  ↓  ↑  ↓
上升沿: U12 数据    U14 数据
下降沿: U13 数据    U15 数据
```

### 供电

| 电源 | 供电对象 | WQ7036AX 引脚 |
|------|----------|--------------|
| MIC_BIAS_0 | U12 + U13（左侧） | B5 |
| MIC_BIAS_1 | U14 + U15（右侧） | A7 |

MIC_BIAS 是麦克风的偏置电压（通常 1.6-3.6V），由 WQ7036AX 内部提供。

### 数据流

```
声波 → SDM0103B 振膜 → Sigma-Delta 调制器 → PDM 1-bit 输出
                                                    │
                                          CLK + DATA 线
                                                    ↓
                                          WQ7036AX PDM Controller
                                                    │
                                          Decimation Filter
                                                    ↓
                                          PCM 16-bit (见 WQ7036AX 音频管道)
```

## 第四层：正常与异常路径

### 正常路径

声波 → 振膜振动 → Sigma-Delta 调制 → PDM 1-bit 输出 → WQ7036AX PDM 控制器接收 → Decimation 滤波 → PCM 数据 → IPC 送到 DCORE 处理

### 异常路径

| 问题 | 现象 | 根因 |
|------|------|------|
| 麦克风无数据 | PDM 数据全零 | MIC_BIAS 未使能或 PDM 时钟未开启 |
| 某一路无声 | 4 路中某一路无数据 | 该路 MIC_BIAS 供电异常或 L/R 配置错误 |
| 噪声大 | 背景噪声明显 | 磁珠（FB）缺失或 PDM 时钟抖动 |
| 串扰 | 一路数据混入另一路 | L/R 引脚电平错误或 DATA 线连接异常 |
| 声音失真 | 语音破音 | MIC_BIAS 电压过高导致麦克风饱和 |
| 时钟不同步 | 采样率异常 | PDM CLK 频率配置错误 |

## 第五层：调试方法

### 1. 检查 MIC_BIAS 电压

万用表测量 MIC_BIAS_0（B5）和 MIC_BIAS_1（A7）引脚电压，确认在 1.6-3.6V 范围内。

### 2. 检查 PDM 时钟

用示波器测量 DMIC_L1_CLK 和 DMIC_R1_CLK 引脚，确认有 2.048MHz 时钟输出。

### 3. 抓取 PDM DATA 波形

用逻辑分析仪抓取 DATA 引脚波形：
- 无声时：DATA 应为 0/1 均匀分布（实际是高频噪声）
- 有声时：DATA 应出现密度变化（脉冲变密或变疏）

### 4. 逐路测试

分别测试 4 路麦克风：
- 遮住 U12 → 观察左声道数据是否变化
- 遮住 U13 → 观察左声道另一路数据是否变化
- 同理测试 U14、U15

### 5. 检查 PDM 配置

在 Kconfig 中确认 `CONFIG_AUDIO_SPK_FB_REF_PDM_CLK_ENABLE` 已启用，PDM 时钟已配置。

问：reGlasses 使用了几颗 SDM0103B？如何分组？
答：4 颗。左声道组（U12+U13，MIC_BIAS_0）和右声道组（U14+U15，MIC_BIAS_1）。每组 2 颗通过 L/R 引脚电平区分前后。

问：一条 PDM DATA 线怎么区分 2 颗麦的数据？
答：L/R=GND 的麦在 CLK 上升沿输出，L/R=VDD 的麦在下降沿输出。WQ7036AX 分别采样两个边沿即可分离两路数据。

问：MIC_BIAS_0 和 MIC_BIAS_1 分别供哪些麦？
答：MIC_BIAS_0 供 U12+U13（左侧组），MIC_BIAS_1 供 U14+U15（右侧组）。

问：磁珠（FB）在麦克风连线中的作用？
答：滤除高频噪声，防止数字信号（CLK 和 DATA 上的高频开关噪声）干扰音频信号。

问：PDM 到 PCM 的转换由什么完成？
答：由 WQ7036AX 内部的 PDM Controller 硬件模块的 Decimation Filter 完成。
