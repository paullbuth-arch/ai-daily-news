# ELM2713 光传感器

## 一句话理解

ELM2713 是一颗**既能测光又能测距离的小芯片**：ALS (Ambient Light Sensor，环境光传感器) 告诉你周围有多亮，PS (Proximity Sensor，近程传感器) 告诉你面前有没有东西。在 reGlasses 里主要用来做**佩戴检测**——眼镜在不在脸上。

## 为什么学它

佩戴检测是智能眼镜的基础功能：摘下来自动暂停、戴上去自动恢复。ELM2713 通过 [[i2c-basics-I2C基础|I2C 连在 WQ7036AX 上]]，是你第一个要调通的 I2C 设备。

## 第一步：在 Source Insight 中找到驱动

1. **`Ctrl+Comma`** 搜索 `CONFIG_LIGHT_SENSOR_DRIVER_ELM2713` → 确认已启用
2. 搜索 `elm2713` 或 `light_sensor` → 找到驱动文件
3. 看初始化流程：I2C 读 Chip ID → 配置 ALS/PS → 使能中断

## 硬件连接

```
ELM2713 (U18)               WQ7036AX
  SCL ──────── R199 ──────── A10 (I2C #1 SCK)
  SDA ──────── R200 ──────── A9  (I2C #1 SDA)
  INT ──────── R198 ──────── M12 (LS_INT, 低电平有效)
  VDD ─────────────────────── AVDD33_AON (3.3V)
  VIO ─────────────────────── VDD18_AON (1.8V IO)
```

| 参数 | 值 |
|------|------|
| I2C 地址 | **0x39** (7-bit, `elm2713_sensor.c:38` 确认 `ELM2713_I2C_ADDR 0x39`) |
| 时钟速率 | 100kHz 或 400kHz |
| 中断触发 | 低电平有效 (LS_INT → M12) |

## 两种功能

### ALS (环境光)

```
环境光 → ELM2713 光电二极管 → ADC → 数字值 (lux)
```

用途：自动调节 LED 亮度（暗环境调暗，亮环境调亮）

### PS (近程)

```
红外 LED 发射 → 碰到物体反射 → ELM2713 红外接收器 → 距离值
```

用途：**佩戴检测**——眼镜鼻梁前方有物体 (脸) → PS 值高 → 判定为佩戴中

## 中断机制

```
ELM2713 检测到事件 (光变化 / 靠近/远离)
    │
    ↓ LS_INT 拉低 (中断)
WQ7036AX M12 触发 GPIO 中断
    │
    ↓ ISR 中发消息给任务
任务中 I2C 读状态寄存器
    │
    ↓ 判断是 ALS 还是 PS 事件
处理事件 (上报 / 佩戴检测)
```

> ⚠️ **中断服务程序 (ISR) 中不能做 I2C 操作**（I2C 会阻塞等 ACK）。ISR 只能发消息，在任务中再做 I2C 读写。

## I2C 操作示例

```c
// 读 Chip ID (验证通信正常)
uint8_t chip_id;
wq_i2c_read(WQ_I2C_PORT_0, 0x39, 0x00, &chip_id, 1);
// 期望读到 ELM2713 的 ID 值

// 读 ALS 数据 (2 字节)
uint8_t als_data[2];
wq_i2c_read(WQ_I2C_PORT_0, 0x39, ALS_DATA_REG, als_data, 2);
uint16_t lux = (als_data[0] << 8) | als_data[1];

// 读 PS 数据
uint8_t ps_data[2];
wq_i2c_read(WQ_I2C_PORT_0, 0x39, PS_DATA_REG, ps_data, 2);
uint16_t proximity = (ps_data[0] << 8) | ps_data[1];
```

#flashcard
问：ELM2713 集成了哪两种传感器？
答：ALS (环境光传感器，检测周围亮度) 和 PS (近程传感器，检测面前是否有物体)。

问：为什么 GPIO 中断服务程序 (ISR) 中不能做 I2C 读写？
答：I2C 操作需要等待 ACK (阻塞等待)，ISR 应该尽快返回。在 ISR 中阻塞会导致系统卡死。正确做法是 ISR 发消息，在任务中做 I2C。
