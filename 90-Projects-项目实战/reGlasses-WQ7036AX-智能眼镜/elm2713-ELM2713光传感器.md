# ELM2713 光传感器

**一句话结论**：ELM2713 是一颗集成了 ALS（环境光）和 PS（近程）两种传感器的 I2C 芯片——ALS 测环境亮度，PS 检测面前是否有物体。在 reGlasses 中主要用于佩戴检测（眼镜是否在脸上）。

---

## 30 秒先看懂

- ELM2713 通过 I2C 连接到 WQ7036AX（I2C 地址 0x39），中断引脚接 M12（LS_INT），低电平触发。
- ALS 检测环境光强，输出 lux 值，用于自动调节 LED 亮度。
- PS 通过红外 LED 发射和反射检测前方物体，用于佩戴检测——鼻梁前方有物体（脸）时 PS 值高。
- 中断触发后，ISR 中不能做 I2C 操作（I2C 会阻塞等待 ACK），必须发消息到任务中处理。
- 在 SDK 中搜索 `CONFIG_LIGHT_SENSOR_DRIVER_ELM2713` 可找到驱动代码。

## 第一层：费曼心智模型

### 类比：保安室的两套监控系统

ELM2713 就像大楼保安室里的两套监控系统：

| 传感器 | 类比 | 说明 |
|--------|------|------|
| **ALS** | 室外光线传感器 | 检测外面是白天还是黑夜，决定要不要开灯 |
| **PS** | 红外摄像头 | 检测门口有没有人，有人靠近就报警 |

**ALS 工作原理**：光电二极管感受光强 → ADC 转换成数字值 → 读寄存器得到 lux 值

**PS 工作原理**：红外 LED 发射红外光 → 碰到物体反射回来 → 接收器检测反射强度 → 距离越近，值越大

### 边界

- ALS 只能测环境光强度，不能测颜色或色温。
- PS 的检测距离有限（通常 <10cm），适合佩戴检测但不适合远距离物体检测。
- ELM2713 通过 I2C 接口配置和读取数据，但中断触发后的 I2C 操作必须在任务中完成，不能在 ISR 中进行。

### 场景推演

**场景：用户戴上眼镜**

1. 用户把眼镜戴上脸，鼻梁处 ELM2713 前方出现物体（人脸）
2. PS 红外反射强度突然升高，超过阈值
3. ELM2713 触发中断，LS_INT 引脚拉低
4. WQ7036AX M12 引脚检测到 GPIO 中断
5. ISR 中发消息给应用任务（不能做 I2C 操作！）
6. 应用任务收到消息，通过 I2C 读取 ELM2713 的状态寄存器
7. 确认是 PS 事件，读取 PS 数据值
8. 判断 PS 值 > 阈值 → 判定为佩戴中
9. 系统唤醒屏幕或恢复播放

## 第二层：原理、时序与约束

### 硬件连接

```
ELM2713 (U18)               WQ7036AX
  SCL ──────── R199 ──────── A10 (I2C #1 SCK)
  SDA ──────── R200 ──────── A9  (I2C #1 SDA)
  INT ──────── R198 ──────── M12 (LS_INT, 低电平有效)
  VDD ─────────────────────── AVDD33_AON (3.3V)
  VIO ─────────────────────── VDD18_AON (1.8V IO)
```

| 参数 | 值 |
|------|------|
| I2C 地址 | 0x39 (7-bit) |
| 时钟速率 | 100kHz 或 400kHz |
| 中断触发 | 低电平有效 (LS_INT → M12) |
| 供电电压 | VDD=3.3V, VIO=1.8V |

### ALS 原理

```
环境光 → ELM2713 光电二极管 → ADC → 数字值 (lux)
```

- ADC 转换结果通过 I2C 读取
- 可配置增益和积分时间调整灵敏度
- 用于自动调节 LED 亮度

### PS 原理

```
红外 LED 发射 → 碰到物体反射 → ELM2713 红外接收器 → 距离值
```

- 红外 LED 驱动电流可配置，影响检测距离
- 检测到物体靠近时 PS 值升高
- 用于佩戴检测——眼镜鼻梁前方有物体（脸）→ PS 值高 → 判定为佩戴中

### 中断机制

```
ELM2713 检测到事件 (光变化 / 靠近/远离)
    │
    ↓ LS_INT 拉低 (中断)
WQ7036AX M12 触发 GPIO 中断
    │
    ↓ ISR 中发消息给任务
任务中 I2C 读状态寄存器
    │
    ↓ 判断是 ALS 还是 PS 事件
处理事件 (上报 / 佩戴检测)
```

> 中断服务程序（ISR）中不能做 I2C 操作（I2C 会阻塞等 ACK）。ISR 只能发消息，在任务中再做 I2C 读写。

### I2C 地址定义

在 `elm2713_sensor.c` 中：
```c
#define ELM2713_I2C_ADDR 0x39
```

### I2C 操作示例

```c
// 读 Chip ID (验证通信正常)
uint8_t chip_id;
wq_i2c_read(WQ_I2C_PORT_0, 0x39, 0x00, &chip_id, 1);
// 期望读到 ELM2713 的 ID 值

// 读 ALS 数据 (2 字节)
uint8_t als_data[2];
wq_i2c_read(WQ_I2C_PORT_0, 0x39, ALS_DATA_REG, als_data, 2);
uint16_t lux = (als_data[0] << 8) | als_data[1];

// 读 PS 数据
uint8_t ps_data[2];
wq_i2c_read(WQ_I2C_PORT_0, 0x39, PS_DATA_REG, ps_data, 2);
uint16_t proximity = (ps_data[0] << 8) | ps_data[1];
```

### 配置使能

在 Kconfig 中搜索 `CONFIG_LIGHT_SENSOR_DRIVER_ELM2713` 确认已启用。

## 第四层：正常与异常路径

### 正常路径

I2C 通信正常 → 中断触发 → ISR 发消息 → 任务读取状态 → 正确识别 ALS/PS 事件 → 执行对应操作

### 异常路径

| 问题 | 现象 | 根因 |
|------|------|------|
| I2C 通信失败 | 读寄存器返回 0xFF | I2C 引脚连接错误或地址不对 |
| 中断不触发 | 物体靠近无反应 | PS 阈值设置过高或中断未使能 |
| 误触发 | 眼镜没戴但 PS 值高 | 红外反射干扰（如放在桌面上） |
| ALS 值异常 | 环境光读数不合理 | ALS 增益/积分时间配置不当 |
| ISR 卡死 | 系统无响应 | ISR 中做了 I2C 操作导致阻塞 |
| 佩戴检测不灵敏 | 戴了但没检测到 | PS 驱动电流太小或阈值过高 |

### 5. 验证阈值配置

检查 ELM2713 的 PS 阈值寄存器配置，确保阈值在合理的范围内。

问：ELM2713 集成了哪两种传感器？
答：ALS（环境光传感器，检测周围亮度）和 PS（近程传感器，检测面前是否有物体）。

问：为什么 GPIO 中断服务程序（ISR）中不能做 I2C 读写？
答：I2C 操作需要等待 ACK（阻塞等待），ISR 应该尽快返回。在 ISR 中阻塞会导致系统卡死。正确做法是 ISR 发消息，在任务中做 I2C。

问：ELM2713 的 I2C 地址和中断引脚是什么？
答：I2C 地址 0x39（7-bit），中断引脚 M12（LS_INT，低电平有效）。

问：在 SDK 中 ELM2713 驱动文件在哪里？
答：`wq-adk/components/peripheral/light_sensor/elm2713/` 目录下。

问：PS 佩戴检测的原理是什么？
答：红外 LED 发射红外光，碰到人脸反射回来，PS 接收器检测反射强度。人脸距离近时反射强，PS 值高，判定为佩戴中。
