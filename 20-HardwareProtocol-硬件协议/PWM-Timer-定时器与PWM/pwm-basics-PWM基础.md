# PWM 基础

**一句话结论（20% 核心）**：PWM 就是用方波的"占空比"来模拟不同的电压或功率——占空比 50% = 一半功率，占空比 100% = 全功率。LED 调光、电机调速、蜂鸣器音量都靠它。

---

## 第一层：核心认知（必须先看懂）

### 1.1 费曼类比：水龙头

PWM 就像你快速开关水龙头：
- 开 50% 时间，关 50% 时间 → 水流是一半（50% 占空比）
- 开 100% 时间 → 全流量（100% 占空比）
- 开关切换得足够快，下游感受不到脉动，只感受到平均流量

```
占空比 25%: ┌┐  ┌┐  ┌┐  ┌┐
            └┘──└┘──└┘──└┘──

占空比 50%: ┌──┐┌──┐┌──┐┌──┐
            └──┘└──┘└──┘└──┘

占空比 75%: ┌────┐┌────┐┌────┐
            └────┘└────┘└────┘
```

### 1.2 核心参数

| 参数 | 含义 | 典型值 |
|------|------|--------|
| **频率** | 每秒多少个周期 | LED: 100Hz-1kHz, 电机: 10-20kHz, 音频: >20kHz |
| **占空比** | 高电平时间占比 | 0%-100% |
| **分辨率** | 占空比的最小步进 | 8bit=256级, 16bit=65536级 |

### 1.3 如果只记得一件事

> PWM = 用方波的占空比控制平均功率。频率要够快（人眼看不出 LED 闪烁 ≥100Hz），分辨率要够细（调光平滑 ≥8bit）。

## 第二层：实战理解

### 2.1 LED 呼吸灯

```c
// 用定时器 PWM 实现 LED 呼吸效果
void timer_pwm_init(void) {
    timer_set_period(TIMER_PWM, 1000);   // 周期 1000 ticks
    timer_set_duty(TIMER_PWM, 0);        // 初始占空比 0
    timer_pwm_start(TIMER_PWM);
}

// 在主循环中逐渐改变占空比
for (int duty = 0; duty <= 1000; duty++) {
    timer_set_duty(TIMER_PWM, duty);
    delay_ms(2);  // 呼吸速度
}
```

### 2.2 常见坑

| 问题 | 现象 | 根因 |
|------|------|------|
| 频率太低 | LED 肉眼可见闪烁 | 低于 50Hz，人眼能感知 |
| 频率太高 | 电机不转 | 超过电机线圈的响应能力 |
| 分辨率不够 | 低亮度 LED 跳动 | 8bit 在低占空比时每一级变化太大 |

### 2.3 在 reGlasses 项目中怎么用

WQ7036AX 的 RGB LED 通过 GPIO 控制（不是 PWM），但蜂鸣器/振动马达等场景会用到 PWM。WQ7036AX 的定时器支持 PWM 输出模式，在 `wqcore/driver/timer/` 下。
