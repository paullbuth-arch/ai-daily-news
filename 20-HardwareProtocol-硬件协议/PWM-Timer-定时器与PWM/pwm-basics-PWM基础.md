# PWM 基础：从定时器比较值到功率控制

> **一句话结论**：PWM（Pulse Width Modulation，脉宽调制）用定时器计数器（counter）和比较器（comparator）的数值比较，产生固定频率但占空比可调的方波。平均电压 = 占空比 × 高电平电压——这是 LED 调光、电机调速、舵机控制和 RC 滤波 DAC 的共同物理基础。WQ7036AX 的硬件定时器通过 `wq_timer_create/start/stop/delete` 管理，PWM 输出由硬件层的定时器比较模式直接产生，没有独立的"PWM HAL"。

本篇的代码锚点：

- **WQ7036AX**：`/home/ys/wq7036a/wq-audio/wqcore/driver/periph/common/hal/timer/wq_timer.h`（定时器 HAL API）、`wqcore/driver/periph/bbb/hw/timer.h`（硬件层定时器）。
- **V861/reGlasses**：当前可编辑 BSP 中未发现独立 PWM 外设的使用。WQ7036AX 的 RGB LED 当前通过 GPIO 开关控制（仅开/关），无 PWM 调光。PWM 证据标记为"当前项目未使用，但硬件支持"。

## 30 秒先看懂

PWM 解决的问题是：**如何用只能输出 0 或 1 的数字引脚，实现"半亮"、"半速"、"1.65V"这样的模拟效果？**

答案是：**快速切换**。如果一秒钟内，50% 的时间输出 3.3V，50% 的时间输出 0V，则平均电压是 1.65V。只要切换速度足够快（LED 需 > 100 Hz，电机需 > 10 kHz），下游感受不到切换，只感受到平均效果。

就像一个台灯的开关，你不去拨动它，而是以每秒 100 次的速度快速开关——台灯看起来就是半亮的，而不是闪烁的。

## 术语先讲清楚

| 术语 | 英文 | 在 PWM 中具体指什么 |
|---|---|---|
| 脉宽调制 | PWM（Pulse Width Modulation） | 用方波中高电平的时间占比（占空比）来控制平均功率或电压。方波频率固定，只改变高电平宽度 |
| 占空比 | duty cycle | 高电平时间占整个周期的百分比。50% 占空比 = 高电平一半时间，低电平一半时间 |
| 频率 | frequency | PWM 方波每秒重复的次数。LED 调光 ≥ 100 Hz，电机调速 ≥ 10 kHz（避开人耳范围），音频 ≥ 40 kHz |
| 周期 | period | 一个完整 PWM 方波的时间长度。周期 = 1/频率。周期 1 ms → 频率 1 kHz |
| 计数器 | counter | 定时器内部的计数器，每个时钟周期加 1。从 0 计数到周期值（ARR，Auto Reload Register），然后归零重新开始 |
| 比较器 | comparator | 将计数器当前值与比较值（CCR，Capture Compare Register）比较。计数器 < CCR → 输出高；计数器 ≥ CCR → 输出低 |
| 分辨率 | resolution | 占空比的最小步进。12-bit 分辨率 = 4096 级（0-4095），每级调整 0.024%。WQ 定时器支持 32-bit 计数 |
| 预分频器 | prescaler | 将定时器时钟源分频，降低计数速度。时钟 24 MHz，预分频 24 → 计数频率 1 MHz |

## 第一层：费曼式心智模型

### 1.1 PWM 像快速开关水龙头

把 PWM 想成你以每秒 100 次的速度开关水龙头：

- 每次都开 50% 时间 → 水流是一半（50% 占空比）
- 每次都开 100% 时间 → 全流量（100% 占空比）
- 开关速度足够快（> 100 Hz），下游感受不到脉动，只感受到**平均流量**

这个类比的关键边界：

1. **频率必须足够高**。LED 需要 > 100 Hz（人眼看不到闪烁），电机需要 > 10 kHz（超过人耳听觉范围，否则线圈振动产生啸叫）。频率由定时器周期决定。
2. **占空比控制的是平均值，不是瞬时值。** PWM 输出永远是方波（0 或 3.3V），只是切换速度让下游"感觉"是平均值。要得到真正的平滑直流电压，需要加 RC 低通滤波器。
3. **占空比和频率是独立的。** 改变占空比不影响频率，改变频率也不影响占空比。但改变周期（ARR）会影响分辨率——周期越大，占空比步进越多。

### 1.2 完整场景演算：定时器产生 1 kHz、50% 占空比 PWM

假设定时器时钟 = 1 MHz（24 MHz 时钟经 24 分频），目标 PWM 频率 = 1 kHz，占空比 = 50%。

```text
第一步：计算周期值（ARR）。
  ARR = 定时器时钟 / PWM 频率 = 1 MHz / 1 kHz = 1000
  计数器从 0 数到 999，然后归零，一个周期 = 1000 个 tick = 1 ms。

第二步：计算比较值（CCR）。
  CCR = ARR × 占空比 = 1000 × 50% = 500
  当计数器 < 500 时，输出高电平；计数器 ≥ 500 时，输出低电平。

第三步：硬件行为逐拍。
  Tick 0:   计数器 = 0，  0 < 500 → 输出高电平
  Tick 250: 计数器 = 250，250 < 500 → 输出高电平
  Tick 500: 计数器 = 500，500 ≥ 500 → 输出低电平
  Tick 750: 计数器 = 750，750 ≥ 500 → 输出低电平
  Tick 999: 计数器 = 999，999 ≥ 500 → 输出低电平
  Tick 1000: 计数器归零，回到 Tick 0。

结果：1 kHz 方波，高电平 500 μs，低电平 500 μs，占空比 50%。
平均电压 = 50% × 3.3V = 1.65V。
```

这个演算说明：改变 CCR 改变占空比（调光/调速），改变 ARR 改变频率（切换更新速度）。

**WQ SDK 事实**：WQ 的 `wq_timer_create(time_us, func, arg, repeat)` 创建的是定时器（用于产生中断），不是 PWM 输出。WQ 的 PWM 输出由硬件层定时器的比较输出模式直接控制 GPIO，不经过 HAL 层的 `wq_timer_*` API。当前 WQ SDK 没有独立的 `wq_pwm_*` HAL 接口。

## 第二层：原理与约束

### 2.1 分辨率与频率的权衡

定时器时钟固定时，PWM 频率和分辨率是互斥的：

```text
时钟 = 24 MHz，目标频率 = 100 kHz：
  ARR = 24M / 100k = 240
  分辨率 = 240 级（约 8 bit），每级 0.42%

时钟 = 24 MHz，目标频率 = 100 Hz：
  ARR = 24M / 100 = 240000
  分辨率 = 240000 级（约 18 bit），每级 0.0004%
```

频率越高 → ARR 越小 → 分辨率越低。所以高速 PWM（如 100 kHz 的 DC-DC 转换器）通常只用 8-10 bit 分辨率，而低速 PWM（如 LED 调光 200 Hz）可以用 16 bit 分辨率。

### 2.2 舵机控制：脉宽控制，不是占空比

舵机不关心占空比，只关心**脉冲宽度**（高电平持续时间）：

- 周期固定 20 ms（50 Hz）
- 脉宽 0.5 ms → 0°、1.5 ms → 90°、2.5 ms → 180°
- 占空比随脉宽变化（0.5/20 = 2.5% ~ 2.5/20 = 12.5%），但这不是关注点

## 第三层：真实 SDK 代码

WQ SDK 的定时器 HAL API（`wqcore/driver/periph/common/hal/timer/wq_timer.h`）：

```c
// 创建定时器（time_us: 微秒，func: 回调，repeat: 是否重复）
uint32_t wq_timer_create(uint32_t time_us, wq_timer_func_t func,
                         void *arg, bool repeat);
WQ_RET wq_timer_start(uint32_t timer);
WQ_RET wq_timer_stop(uint32_t timer);
WQ_RET wq_timer_delete(uint32_t timer);
```

这是定时器中断 API，不是 PWM 输出 API。WQ 的 PWM 功能通过硬件层定时器比较输出模式实现，走 `bbb/hw/timer.h` 的寄存器操作。当前两套 SDK 中没有独立的 PWM HAL 抽象层。

## 第四层：正常路径与异常路径

- **正常**：配置定时器 → 配置比较输出 → 使能 PWM 输出 → 调整占空比 → 停止
- **异常**：频率太高导致分辨率不够 → 低占空比时 LED 阶梯式跳动
- **异常**：频率太低 → LED 闪烁、电机啸叫
- **异常**：GPIO 复用冲突 → PWM 输出引脚无波形（被配置为普通 GPIO）

## 第五层：调试方法

| 现象 | 假设 | 证据 | 修复 |
|---|---|---|---|
| LED 闪烁 | 频率 < 50 Hz | 示波器测周期 | 增大 ARR 或降低时钟分频 |
| 电机啸叫 | 频率在 1-10 kHz | 示波器测频率 | 提高到 > 20 kHz |
| 低亮度 LED 跳动 | 分辨率不够 | 计算 ARR 值 | 降低 PWM 频率以增大 ARR |
| 无波形输出 | GPIO 复用冲突 | 检查引脚功能配置 | 确保 GPIO 被配置为定时器输出 |

## 自测题

1. **PWM 的占空比和频率分别控制什么？** 占空比控制平均功率/电压，频率控制更新速度。LED 调光：改变占空比；电机调速：改变占空比；舵机：改变脉宽（频率固定 50 Hz）。
2. **ARR = 1000, CCR = 250，占空比是多少？** 25%。
3. **为什么电机 PWM 频率要 > 10 kHz？** 低于 10 kHz 的 PWM 频率落在人耳听觉范围内（20 Hz-20 kHz），电机线圈振动会产生可闻啸叫。
4. **定时器时钟 24 MHz，目标 100 kHz PWM，分辨率是多少？** ARR = 240，约 8 bit。
5. **WQ 的 `wq_timer_create` 能直接产生 PWM 输出吗？** 不能。它创建的是定时器中断，用于定时回调。PWM 输出需要硬件层定时器比较输出模式。
