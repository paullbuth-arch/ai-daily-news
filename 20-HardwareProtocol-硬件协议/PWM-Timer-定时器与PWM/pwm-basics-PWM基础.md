# PWM 基础

**一句话结论（20% 核心）**：PWM（Pulse Width Modulation，脉宽调制）用方波的占空比来模拟不同的电压或功率——100% 占空比 = 全功率，50% = 一半功率，0% = 关。LED 调光、电机调速、蜂鸣器音量、甚至模拟 DAC 输出都靠它。核心参数：频率（多快）和占空比（高电平占比）。

---

## 第一层：核心认知（必须先看懂）

### 1.1 费曼类比：快速开关水龙头

PWM 就像你以一秒钟 100 次的速度开关水龙头：
- 每次都开 50% 时间 → 水流是一半（50% 占空比）
- 每次都开 100% 时间 → 全流量（100% 占空比）
- 开关速度足够快（>100Hz），下游感受不到脉动，只感受到**平均流量**

```
占空比 25%: ┌┐  ┌┐  ┌┐  ┌┐   平均电压 = 25% × 3.3V = 0.825V
            └┘──└┘──└┘──└┘──

占空比 50%: ┌──┐┌──┐┌──┐┌──┐   平均电压 = 50% × 3.3V = 1.65V
            └──┘└──┘└──┘└──┘

占空比 75%: ┌────┐┌────┐┌────┐   平均电压 = 75% × 3.3V = 2.475V
            └────┘└────┘└────┘
```

### 1.2 PWM 的关键参数

| 参数 | 含义 | 怎么选 | 选错后果 |
|------|------|--------|---------|
| **频率** | 每秒多少个周期 | LED≥100Hz, 电机 10-20kHz, 音频>20kHz | 频率太低→LED 闪烁/电机噪音 |
| **占空比** | 高电平时间占比 | 0%-100% | |
| **分辨率** | 占空比的最小步进 | 8bit=256级, 16bit=65536级 | 分辨率太低→低亮度时 LED 跳动 |

### 1.3 PWM 的硬件实现：定时器

```
定时器计数器 + 比较器 = PWM 发生器

计数器: 0 → 1 → 2 → ... → 999 → 0 → 1 → ...  (周期 = 1000)
比较值: 500

当计数器 < 比较值 → 输出高电平
当计数器 ≥ 比较值 → 输出低电平

结果: 50% 占空比, 频率 = 定时器时钟 / 1000
```

**改变比较值就改变占空比，改变周期就改变频率。** 这是所有 PWM 硬件的基本原理。

### 1.4 如果只记得一件事

> PWM = 用方波的占空比控制平均功率。改变占空比→改变功率，改变频率→改变更新速度。LED 调光≥100Hz，电机调速 10-20kHz，带 RC 滤波可以当 DAC 用。

## 第二层：实战理解

### 2.1 LED 呼吸灯完整实现

```c
// WQ7036AX 定时器 PWM 实现 LED 呼吸灯
// 定时器时钟 = 24MHz, 预分频 = 24 → 1MHz tick
// 周期 = 1000 → PWM 频率 = 1MHz / 1000 = 1kHz (>100Hz, 不闪烁)
// 分辨率 = 1000 → 约 10bit

void pwm_init(void) {
    timer_set_prescaler(TIMER_PWM, 24);    // 预分频 24
    timer_set_period(TIMER_PWM, 1000);     // 周期 1000 → 1kHz
    timer_set_duty(TIMER_PWM, 0);          // 初始占空比 0
    timer_pwm_start(TIMER_PWM);
}

// 呼吸效果：渐亮→渐暗→循环
void breathe_effect(void) {
    static int duty = 0;
    static int direction = 1;

    duty += direction;
    if (duty >= 1000) direction = -1;      // 到达最亮，开始变暗
    if (duty <= 0)    direction = 1;       // 到达最暗，开始变亮

    timer_set_duty(TIMER_PWM, duty);
    vTaskDelay(pdMS_TO_TICKS(5));          // 5ms 一步，呼吸周期约 10 秒
}
```

### 2.2 PWM 做 DAC（数模转换）

```c
// PWM + RC 低通滤波 = 最便宜的 DAC
// R = 1kΩ, C = 10μF → 截止频率 = 1/(2πRC) ≈ 16Hz
// PWM 频率应该 >> 截止频率，如 10kHz

// 输出 1.65V (50% of 3.3V)
pwm_set_duty(50);  // 假设 0-100

// 输出正弦波（查表法）
const uint8_t sine_table[256] = {
    128, 131, 134, 137, ...  // 预计算的正弦波值
};
for (int i = 0; i < 256; i++) {
    pwm_set_duty(sine_table[i]);
    delay_us(100);  // 100μs 一步 → 256 步 = 25.6ms 周期 ≈ 39Hz
}
```

### 2.3 常见坑

| 问题 | 现象 | 排查方法 | 根因 |
|------|------|---------|------|
| 频率太低 | LED 闪烁、电机噪音 | 示波器测量实际频率 | 低于人眼感知阈值（~50Hz）或人耳听觉范围（<20kHz） |
| 频率太高 | 电机不转、电磁干扰 | 降低频率对比 | 电机线圈电感大，高频 PWM 电流无法建立 |
| 分辨率不够 | 低亮度 LED 阶梯式跳动 | 用 16bit 代替 8bit | 低占空比时每一级相对变化太大 |
| GPIO 和 PWM 复用冲突 | PWM 输出引脚没波形 | 检查引脚复用配置 | 引脚被配置为普通 GPIO 而不是 PWM 输出 |

### 2.4 在 reGlasses 项目中怎么用

WQ7036AX 的 RGB LED 当前通过 GPIO 控制（只有开/关，没有亮度调节）。如果后续需要 LED 调光或蜂鸣器音量控制，需要用到 PWM。WQ7036AX 的定时器支持 PWM 输出模式，驱动在 `wqcore/driver/timer/` 下。

## 第三层：深入扩展

### 3.1 舵机控制（PWM 的经典应用）

```
舵机用 PWM 的脉冲宽度控制角度（不是占空比！）:
  周期固定 20ms (50Hz)
  脉冲宽度 0.5ms → 0 度
  脉冲宽度 1.5ms → 90 度（中间位置）
  脉冲宽度 2.5ms → 180 度

  0.5ms: ┌┐──────────────────┐
         └┘──────────────────┘
  1.5ms: ┌───┐───────────────┐
         └───┘───────────────┘
  2.5ms: ┌─────┐─────────────┐
         └─────┘─────────────┘
  ←────────── 20ms ──────────→
```

### 3.2 常见问题

- **PWM 频率和占空比怎么换算？** 频率 = 1/周期。占空比 = 高电平时间/周期 × 100%。例：周期 1ms，高电平 0.3ms → 频率 1kHz，占空比 30%。
- **PWM 和模拟电压的区别？** 经过 RC 滤波后，PWM 输出的平均电压 = 占空比 × 高电平电压。但要注意：PWM 输出的是数字信号（0/1），不是真正的模拟电压。需要滤波才能得到平滑的直流电平。
- **为什么电机 PWM 频率要 10-20kHz？** 低于 10kHz 会产生人耳可听的啸叫（线圈振动），高于 20kHz 超出人耳范围。但频率太高会增加开关损耗。
