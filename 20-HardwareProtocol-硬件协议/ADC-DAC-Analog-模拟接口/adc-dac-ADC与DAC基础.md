# ADC/DAC 基础

**一句话结论（20% 核心）**：ADC 把模拟量（电压、温度、声音）变成数字量，DAC 把数字量变回模拟量。嵌入式世界里，ADC 用来读传感器，DAC 用来输出模拟信号（如音频）。

---

## 第一层：核心认知（必须先看懂）

### 1.1 费曼类比：温度计和音量旋钮

- **ADC** = 数字温度计：把连续的物理量（温度）变成离散的数字（37.5°C）
- **DAC** = 音量旋钮：把数字（音量 0-100）变成连续的模拟量（电压 0-3.3V）

```
模拟世界（连续）                    数字世界（离散）
   温度 37.5°C ──→ ADC ──→ 0x25
   声音波形    ──→ ADC ──→ PCM 采样数据
   电压 1.8V   ──→ ADC ──→ 0x8B

   数字 0x80   ──→ DAC ──→ 电压 1.65V
   PCM 数据    ──→ DAC ──→ 声音波形
```

### 1.2 核心参数

| 参数 | 含义 | 典型值 | 怎么选 |
|------|------|--------|--------|
| **分辨率** | 输出数字的位数 | 8/10/12/16 bit | 越高越精细，12bit=4096 级 |
| **采样率** | 每秒采样次数 | 1k-1M sps | 信号的最高频率 × 2（奈奎斯特定理） |
| **参考电压** | 满量程对应的电压 | 3.3V / 5V | 决定测量范围 |
| **通道数** | 能同时采几路 | 1-16 | 看传感器数量 |

### 1.3 如果只记得一件事

> ADC = 模拟→数字，DAC = 数字→模拟。分辨率越高越精细，采样率要 ≥ 信号最高频率的 2 倍。

## 第二层：实战理解

### 2.1 电池电压检测（最常用的 ADC 场景）

```c
// 读取电池电压：电池 → 分压电阻 → ADC 引脚 → 数字值 → 换算电压
uint16_t adc_raw = adc_read(ADC_CH_BATTERY);
float voltage = (adc_raw / 4096.0) * 3.3 * (100.0 + 47.0) / 47.0;
// 分压比: 100kΩ + 47kΩ, 参考电压 3.3V, 12bit ADC
```

### 2.2 常见坑

| 问题 | 现象 | 根因 |
|------|------|------|
| 参考电压不稳 | ADC 读数跳动 | 参考电压有噪声，加电容滤波 |
| 输入阻抗不匹配 | 读数偏低 | ADC 输入阻抗不够大，分走电流 |
| 采样率不够 | 信号失真 | 不满足奈奎斯特定理，出现混叠 |

### 2.3 在 reGlasses 项目中怎么用

WQ7036AX 的 ADC 用于电池电压检测和充电状态监测。音频采集走的是 PDM 数字麦克风（内部有专用 ADC），不走通用 ADC 通道。
