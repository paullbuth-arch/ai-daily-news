# ADC/DAC 基础：从模拟电压到数字编码

> **一句话结论**：ADC（Analog-to-Digital Converter，模数转换器）把连续的模拟电压量化为离散的数字编码——分辨率和采样率决定了精度和速度。SAR（逐次逼近）是 MCU 通用 ADC 的主流架构（中速中精度），Σ-Δ（sigma-delta）是音频 ADC 的主流架构（低速高精度）。WQ7036AX 的通用 ADC 是 SAR 型用于电池检测，音频采集由 PDM 接口内部的 Σ-Δ ADC 完成。DAC 反之——把数字编码还原为模拟电压，PWM + RC 滤波是最便宜的 DAC 替代方案。

本篇的代码锚点：

- **WQ7036AX**：`/home/ys/wq7036a/wq-audio/wqcore/components/audsys/device/aud_adc.c`（音频 ADC 设备层）、`wqcore/driver/audio/declare/wq_audio_adc_declare.h`（音频 ADC API 声明）。
- **V861/reGlasses**：当前可编辑 BSP 中未发现独立 ADC 外设的使用。WQ7036AX 的电池电压检测通过分压电阻接入 ADC 通道。

## 30 秒先看懂

ADC 解决的根本问题是：**真实的物理世界是连续的（温度、电压、声音），而计算机只能处理离散的数字。如何把连续的电压变成计算机能理解的数字？**

类比：用一把尺子量水温。尺子上的刻度是"分辨率"（12-bit = 4096 个刻度），你每分钟量一次是"采样率"。量得越密（刻度多），精度越高；量得越快（采样率高），越能捕捉温度的快速变化。

DAC 是反过来：把数字（如"音量 50"）变成连续的电压（如 1.65V），推动扬声器发声。

## 术语先讲清楚

| 术语 | 英文 | 在 ADC/DAC 中具体指什么 |
|---|---|---|
| 模数转换 | ADC | 将模拟电压量化为数字编码。输入：连续电压（如 0-3.3V），输出：离散数字（如 0-4095） |
| 数模转换 | DAC | 将数字编码还原为模拟电压。输入：数字（如 0x80），输出：电压（如 1.65V） |
| 分辨率 | resolution | ADC 输出的位数。12-bit = 4096 级，每级电压 = Vref / 4096。分辨率越高，能分辨的电压变化越小 |
| 采样率 | sample rate | 每秒采样次数。根据奈奎斯特定理，采样率必须 ≥ 信号最高频率的 2 倍，否则出现混叠（aliasing） |
| 参考电压 | Vref（Reference Voltage） | ADC 的满量程输入电压。输入 0V → 输出 0，输入 Vref → 输出最大值。Vref 的稳定性和精度直接影响 ADC 精度 |
| 量化误差 | quantization error | ADC 把连续电压映射到离散编码时引入的舍入误差。最大量化误差 = ±0.5 LSB。这是 ADC 的固有特性，无法消除 |
| SAR | Successive Approximation Register | 逐次逼近型 ADC，用二分法逐位确定电压编码。中速（1k-5M sps）、中高精度（10-16 bit）、低功耗。MCU 内置 ADC 的主流架构 |
| Σ-Δ | Sigma-Delta | 过采样 + 噪声整形 + 数字滤波。低速（10-1k sps）、高精度（16-24 bit）。音频 ADC 的标准架构，WQ PDM 麦克风内部即为 Σ-Δ 调制器 |
| ENOB | Effective Number of Bits | 有效位数。因为噪声、非线性和参考电压误差，12-bit ADC 的实际有效精度通常只有 10-11 bit |
| 混叠 | aliasing | 采样率不足时，高频信号被"折叠"成低频伪信号。例如 9 kHz 信号用 10 kHz 采样，会误读为 1 kHz 信号 |

## 第一层：费曼式心智模型

### 1.1 ADC 像用尺子量水位

把 ADC 想成用一把有刻度的尺子量水位：

- 尺子长度 = Vref（如 3.3V 对应尺子全长）
- 刻度数量 = 2^分辨率（12-bit = 4096 个刻度，每格 3.3V/4096 ≈ 0.8 mV）
- 每次量一次 = 一次采样（采样率 = 每秒量几次）

水位 1.65V 时，尺子读数 = 1.65 / 3.3 × 4096 = 2048 = 0x800。

这个类比的关键边界：

1. **尺子不会比刻度更精确。** 最大读不准的量 = 半个刻度（±0.5 LSB）。这是量化误差，任何 ADC 都有。
2. **尺子本身可能不准。** 如果 Vref 实际上是 3.2V 而不是 3.3V，所有读数都偏高 3%。这就是 Vref 精度的重要性。
3. **量得太慢会漏掉变化。** 如果水位每秒波动 10 次，你每秒只量 5 次（5 Hz 采样率），你会漏掉一半的波动，甚至看到"假波动"（混叠）。

### 1.2 完整场景演算：SAR ADC 测量 1.8V 电池电压

WQ7036AX 的 SAR ADC 为 12-bit，Vref = 3.3V，输入电压 = 1.8V。

```text
第一步：理论输出值。
  ADC 输出 = (Vin / Vref) × 2^12 = (1.8 / 3.3) × 4096 = 2234.2
  取整 = 2234 = 0x8BA

第二步：实际可能的值（考虑量化误差 ±0.5 LSB 和噪声）。
  实际输出可能在 2232 ~ 2236 之间（±2 LSB 噪声）。

第三步：多次采样取平均提高精度。
  采样 16 次：2234, 2233, 2235, 2234, 2232, 2234, 2236, 2233...
  平均值 ≈ 2234 → 电压 = 2234 × 3.3V / 4096 ≈ 1.800V
  有效分辨率提高：16× 过采样 → 增加 2 bit → 相当于 14-bit ADC
```

## 第二层：原理与约束

### 2.1 SAR ADC 的二分法原理

SAR ADC 像猜数字游戏：在 0-4095 之间猜一个数，每次猜中间值，比较器告诉你是猜高了还是猜低了。

```text
目标值 = 2234（1.8V）:
  第 1 次猜：2048（DAC 输出 1.65V），比较器：1.8V > 1.65V → 猜低了，D11=1
  第 2 次猜：3072（1.65 + 0.825），比较器：1.8V < 2.475V → 猜高了，D10=0
  第 3 次猜：2560，比较器：1.8V < 2.06V → 猜高了，D9=0
  ... 继续 12 次
  最终结果：2234 = 0x8BA
```

每次逼近需要 1 个时钟周期，12-bit ADC 需要 12 个周期完成一次转换。如果 ADC 时钟 = 10 MHz，一次转换 = 1.2 μs，采样率 ≈ 833k sps。

### 2.2 奈奎斯特定理

采样率必须 ≥ 信号最高频率的 2 倍，否则高频信号会"伪装"成低频信号（混叠）：

```text
信号频率 = 9 kHz，采样率 = 10 kHz：
  10 kHz 采样 9 kHz 信号 → 每个周期只能采约 1.1 个点
  采样结果看起来像 1 kHz 的信号（10k - 9k = 1k）
  这是混叠——9 kHz 的高频变成了 1 kHz 的假信号
```

预防：在 ADC 输入前加低通滤波器（抗混叠滤波器），滤除 > 采样率/2 的频率成分。

## 第三层：真实 SDK 代码

WQ 的音频 ADC 通过 `wq_audio_adc_declare.h` 声明，音频设备层 `aud_adc.c` 管理。通用 ADC（SAR ADC for 电池检测）通过硬件层直接操作寄存器。

当前 WQ SDK 没有独立的通用 ADC HAL（类似 `wq_adc_read(channel)` 这样的 API 未在 `common/hal/` 下找到）。电池电压检测通过应用层直接读取 ADC 寄存器或使用音频 ADC 的计量通道。

## 第四层：正常路径与异常路径

- **正常**：配置 ADC 通道 → 启动转换 → 等待完成 → 读取结果 → 换算为电压
- **异常**：Vref 不稳定 → 读数整体偏移
- **异常**：输入阻抗不匹配 → 读数偏低（ADC 从信号源分走电流）
- **异常**：采样率不够 → 混叠（高频信号变为低频伪信号）

## 第五层：调试方法

| 现象 | 假设 | 证据 | 修复 |
|---|---|---|---|
| 读数跳动 > 20 LSB | 电源噪声 | 示波器看 Vref 引脚 | Vref 加去耦电容 |
| 读数明显偏低 | 输入阻抗不匹配 | 计算分压网络阻抗 | 降低分压电阻值或加运放缓冲 |
| 高频信号读不准 | 采样率不够 | 对比已知频率信号的采样结果 | 提高采样率或加抗混叠滤波 |

## 自测题

1. **12-bit ADC, Vref=3.3V，1 LSB 对应多少 mV？** 3.3V / 4096 ≈ 0.806 mV。
2. **SAR 和 Σ-Δ ADC 的区别？** SAR：中速中精度，逐次逼近，适合通用测量。Σ-Δ：低速高精度，过采样+噪声整形，适合音频。
3. **为什么 12-bit ADC 的有效位数只有 10-11 bit？** 噪声、非线性、Vref 误差降低了实际精度。ENOB 参数在数据手册中给出。
4. **采样率 10 kHz 能正确采集的最高信号频率是多少？** 5 kHz（奈奎斯特定理：采样率 / 2）。
5. **PWM + RC 滤波为什么能做 DAC？** PWM 方波经 RC 低通滤波后，输出平均值 = 占空比 × VDD。改变占空比改变输出电压。
