# ADC/DAC 基础

**一句话结论（20% 核心）**：ADC 把模拟量（电压、温度、声音）变成数字量，DAC 反过来。核心参数：分辨率（多少位）、采样率（多快）、参考电压（多大范围）。ADC 选型三板斧：看分辨率够不够、采样率够不够快、输入范围对不对。WQ7036AX 的 ADC 用于电池检测，音频采集走专用 PDM 接口（内部集成 Σ-Δ ADC）。

---

## 第一层：核心认知（必须先看懂）

### 1.1 费曼类比：温度计和音量旋钮

- **ADC** = 数字温度计：把连续的物理量（温度）变成离散的数字（37.5°C → 0x25）
- **DAC** = 音量旋钮：把数字（音量 0-100）变成连续的模拟量（电压 0-3.3V）
- **分辨率** = 温度计的刻度精度：8 位 = 256 格，12 位 = 4096 格

```
模拟世界（连续）                    数字世界（离散）
   温度 37.5°C ──→ ADC ──→ 0x25 (8bit) / 0x258 (12bit)
   声音波形    ──→ ADC ──→ PCM 采样数据
   电压 1.8V   ──→ ADC ──→ 0x8B (12bit, Vref=3.3V)

   数字 0x80   ──→ DAC ──→ 电压 1.65V (Vref=3.3V)
   PCM 数据    ──→ DAC ──→ 声音波形 → 扬声器
```

### 1.2 ADC 的三种架构

| 类型 | 原理 | 速度 | 分辨率 | 功耗 | 典型用途 |
|------|------|------|--------|------|---------|
| **SAR** | 逐次逼近，二分法猜电压 | 中（1k-5M sps） | 中高（10-16bit） | 低 | 通用 MCU ADC、传感器 |
| **Σ-Δ** | 过采样+噪声整形+数字滤波 | 慢（10-1k sps） | 高（16-24bit） | 中 | 音频、精密测量 |
| **Flash** | 2^N 个比较器同时比较 | 极快（100M-1G sps） | 低（6-8bit） | 高 | 高速示波器、雷达 |

**WQ7036AX 的 ADC 架构**：通用 ADC 是 SAR 型（12bit，电池检测），音频采集用 PDM 接口（内部 Σ-Δ ADC，16bit，16kHz）。

### 1.3 核心参数详解

| 参数 | 含义 | 怎么算 | 选型建议 |
|------|------|--------|---------|
| **分辨率** | ADC 输出位数 | 12bit = 4096 级 | 看精度需求：电池检测 10bit 够，音频 16bit |
| **采样率** | 每秒采样次数 | 1k-5M sps | ≥ 信号最高频率 × 2（奈奎斯特） |
| **参考电压** | 满量程输入电压 | 3.3V / 5V | 输入信号范围不能超过 Vref |
| **INL/DNL** | 积分/微分非线性 | datasheet 给出 | INL < 1 LSB 算好，> 2 LSB 精度差 |
| **ENOB** | 有效位数 | 总比标称分辨率低 1-2 bit | 12bit ADC 的 ENOB 通常只有 10-11 bit |

### 1.4 奈奎斯特采样定理

```
要完整还原一个信号，采样率必须 ≥ 信号最高频率的 2 倍。

人声: 最高 ~4kHz → 采样率 ≥ 8kHz (电话用 8kHz)
音乐: 最高 ~20kHz → 采样率 ≥ 40kHz (CD 用 44.1kHz)

采样率不够 → 混叠 (Aliasing):
  高频信号被"折叠"成低频，听起来像奇怪的噪音
  解决: 采样前加低通滤波器（抗混叠滤波器）
```

### 1.5 如果只记得一件事

> ADC = 模拟→数字，DAC = 数字→模拟。SAR 通用（中速中精度），Σ-Δ 精密（低速高精度，音频用），Flash 极速（低精度）。分辨率看位数，采样率看奈奎斯特（≥ 2×信号频率），Vref 看输入范围。

## 第二层：实战理解

### 2.1 电池电压检测完整实现

```c
// WQ7036AX 电池电压检测
// 硬件: 电池 → 分压电阻 → ADC 引脚
// 分压比: R1=100kΩ, R2=47kΩ
// Vbat = ADC_voltage × (R1+R2)/R2

#define ADC_VREF      3.3f     // 参考电压
#define ADC_RESOLUTION 4096    // 12bit
#define R1            100000   // 100kΩ
#define R2            47000    // 47kΩ

// 读取原始 ADC 值
uint16_t adc_raw = adc_read(ADC_CH_BATTERY);

// 计算 ADC 引脚电压
float adc_voltage = (adc_raw / (float)ADC_RESOLUTION) * ADC_VREF;

// 计算实际电池电压
float battery_voltage = adc_voltage * (R1 + R2) / R2;

printf("Battery: %.2fV (raw=%d)\n", battery_voltage, adc_raw);

// 为什么需要多次采样取平均？
// 单次采样可能被噪声干扰，取 16 次平均值提高精度
uint32_t sum = 0;
for (int i = 0; i < 16; i++) {
    sum += adc_read(ADC_CH_BATTERY);
}
uint16_t adc_avg = sum / 16;
```

### 2.2 ADC 噪声来源和抑制

| 噪声来源 | 现象 | 解决方法 |
|---------|------|---------|
| **电源噪声** | 读数持续跳动 ±5 LSB | Vref 引脚加 0.1μF + 10μF 电容滤波 |
| **量化噪声** | 最低位随机翻转 | 这是 ADC 的固有特性，过采样+平均可以降低 |
| **热噪声** | 高温时噪声增大 | 减少 ADC 输入阻抗，加屏蔽 |
| **EMI 干扰** | 手机靠近时读数跳动 | PCB 走线远离射频区域，加 RC 低通滤波 |

### 2.3 过采样：用采样率换精度

```
每增加 4 倍采样率 → 有效分辨率增加 1 bit

12bit ADC, 采样 16 次取平均 → 有效分辨率 14bit
(16 = 4², 所以增加 2 bit)

int32_t sum = 0;
for (int i = 0; i < 16; i++) {
    sum += adc_read(ch);
}
int16_t result = sum >> 2;  // 除以 4，14bit 有效精度
```

### 2.4 常见坑

| 问题 | 现象 | 排查方法 | 根因 |
|------|------|---------|------|
| 参考电压不稳 | ADC 读数跳动 >20 LSB | 示波器看 Vref 引脚波形 | 电源纹波大，或 Vref 去耦电容不够 |
| 输入阻抗太高 | 读数明显偏低 | 计算分压网络的实际阻抗 | ADC 输入阻抗不够大，从分压网络分走了电流 |
| 采样率不够 | 信号波形失真 | 比较原信号和采样后信号 | 不满足奈奎斯特定理，出现混叠 |
| 未做软件滤波 | 读数跳动但波形正常 | 加滑动平均滤波对比 | 正常噪声，需要软件滤波而非硬件修改 |

### 2.5 在 reGlasses 项目中怎么用

WQ7036AX 的 ADC 用于：
- **电池电压检测**：通过分压电阻接 ADC 通道，定期采样计算电量
- **充电状态检测**：检测充电 IC 的状态引脚电平变化

音频采集不走通用 ADC——PDM 数字麦克风内部有专用 Σ-Δ ADC，输出直接是 1-bit PDM 流，WQ7036AX 的 PDM Controller 硬件做 Decimation 转 PCM。

## 第三层：深入扩展

### 3.1 DAC 的两种实现

| 类型 | 原理 | 精度 | 速度 | 用途 |
|------|------|------|------|------|
| **R-2R 梯形网络** | 用精密电阻分压 | 中（8-12bit） | 快 | 通用 DAC |
| **Σ-Δ DAC** | 过采样+噪声整形 | 高（16-24bit） | 慢 | 音频 DAC |
| **PWM + 低通滤波** | 用 PWM 占空比模拟电压 | 中（8-10bit） | 慢 | 最便宜的"DAC"，LED 调光 |

### 3.2 常见问题

- **SAR 和 Σ-Δ ADC 怎么选？** SAR：速度快，适合多通道扫描、传感器读取。Σ-Δ：精度高，适合音频、精密测量。MCU 内置的通常是 SAR。
- **为什么 12bit ADC 的有效位数只有 10-11bit？** 因为噪声、非线性、参考电压误差等因素，实际精度低于理论分辨率。ENOB 参数在 datasheet 中给出。
- **ADC 输入阻抗为什么重要？** 如果 ADC 输入阻抗 < 信号源阻抗的 10 倍，ADC 会从信号源分走可观的电流，导致测量值偏低。
