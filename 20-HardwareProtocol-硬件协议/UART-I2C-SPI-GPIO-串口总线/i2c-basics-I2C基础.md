# I2C 基础

**一句话结论（20% 核心）**：I2C 是两线总线（SCL 时钟 + SDA 数据），靠地址区分不同的从设备，是连接传感器最常用的接口。reGlasses 用它连接光传感器和充电 IC。

---

## 第一层：核心认知（必须先看懂）

### 1.1 费曼类比：教室点名

I2C 就像**老师（Master）点名**：
- 老师喊一个学号（**7-bit 地址**，如 0x39）
- 被点到的学生（**Slave**）站起来回答问题
- 其他学生保持安静（**不匹配地址的 Slave 忽略通信**）
- 只有两根线：SCL（喊话的节奏）和 SDA（传答案）

```
       3.3V          3.3V
        │             │
       [R]           [R]      ← 上拉电阻（4.7kΩ，把线拉到高电平）
        │             │
SCL ────┼─────────────┼────  Master + Slave1 + Slave2 + ...
SDA ────┼─────────────┼────  （所有设备共享这两根线）
        │             │
     ┌──┴──┐      ┌──┴──┐
     │Master│      │Slave│
     └─────┘      └─────┘
```

### 1.2 为什么需要上拉电阻？

**关键理解**：I2C 的设备只能把线**拉低**（接通 GND），不能主动把线**拉高**。上拉电阻负责把线拉到高电平。这样设计的好处是：多个设备可以共享同一根线，不会出现一个设备输出高、另一个输出低导致的短路。

**费曼类比**：上拉电阻就像一根弹簧，默认把线拉到高位置。任何一个设备都可以把线按下去（拉低），但松手后弹簧自动弹回高位置。

### 1.3 Start 和 Stop：怎么开始和结束一次通信？

```
Start: SCL 高电平时，SDA 从高→低  （老师说"注意，我要点名了"）
Stop:  SCL 高电平时，SDA 从低→高  （老师说"下课"）

SCL: ──────╱─╲─╱─╲─╱─╲──────
SDA: ──╲                     ╱──
       Start                 Stop
```

**Start 和 Stop 是唯一 SDA 在 SCL 高电平时发生变化的时刻**——正常传输数据时，SDA 只在 SCL 低电平时变化。

### 1.4 写一个寄存器的完整流程

以 ELM2713 光传感器（地址 0x39）为例，写寄存器 0x10 = 0x03：

```
[S] [0x72] [A] [0x10] [A] [0x03] [A] [P]
 │    │     │    │     │    │     │    │
 │    │     │    │     │    │     │    └─ Stop
 │    │     │    │     │    │     └────── Slave 的 ACK（"收到了"）
 │    │     │    │     │    └──────────── 要写入的数据 0x03
 │    │     │    │     └─────────────── Slave 的 ACK
 │    │     │    └──────────────────── 寄存器地址 0x10
 │    │     └───────────────────────── Slave 的 ACK
 │    └────────────────────────────── 地址+写位 (0x39<<1 | 0 = 0x72)
 └─────────────────────────────────── Start
```

**注意**：I2C 地址是 7-bit，但实际发送时会在最低位加上 R/W 位（0=写，1=读），所以 0x39 变成 0x72（写）或 0x73（读）。

### 1.5 如果只记得一件事

> I2C = 两根线（SCL 时钟 + SDA 数据）+ 上拉电阻 + 7-bit 地址寻址 + Start/Stop 条件。写寄存器 = Start → 地址+W → 寄存器号 → 数据 → Stop。读寄存器需要先"假装写"寄存器号，再 Restart 切换为读。

## 第二层：实战理解

### 2.1 WQ7036AX 的 I2C 驱动 API

SDK 中 I2C 驱动位于 `wqcore/driver/i2c/`，核心 API：

```c
// 写寄存器
WQ_RET wq_i2c_write(WQ_I2C_PORT port, uint8_t addr,
                    uint8_t reg, const uint8_t *data, uint8_t len);

// 读寄存器
WQ_RET wq_i2c_read(WQ_I2C_PORT port, uint8_t addr,
                   uint8_t reg, uint8_t *buf, uint8_t len);
```

典型用法（读 ELM2713 的光照值）：

```c
uint8_t als_data[2];
wq_i2c_read(I2C_PORT_0, 0x39, 0x0C, als_data, 2);
uint16_t lux = (als_data[1] << 8) | als_data[0];
```

### 2.2 reGlasses 中的两路 I2C

| 参数 | I2C #1 | I2C #2 |
|---|---|---|
| 引脚（SCK/SDA） | A10 / A9 | B8 / B7 |
| 从设备 | ELM2713 光传感器 | 充电 IC |
| 从设备地址 | **0x39** | 充电 IC 规格书定义 |
| 中断引脚 | LS_INT（M12） | CHARGE_INT（M11） |

### 2.3 常见坑

| 问题 | 现象 | 根因 |
|---|---|---|
| 地址左移错误 | 收不到 ACK | 7-bit 地址没左移，或忘了加 R/W 位 |
| 上拉电阻缺失 | SDA 一直为低 | 没有上拉，线浮空 |
| 总线被占用 | SDA 一直为低 | 某个 Slave 把 SDA 拉低了没释放 |
| 速率不匹配 | 通信不稳定 | Slave 只支持 100kHz，Master 配了 400kHz |

## 第三层：深入扩展

### 3.1 UART vs I2C vs SPI 对比

| | UART | I2C | SPI |
|---|---|---|---|
| 线数 | 2 (TX+RX) | **2 (SDA+SCL)** | 4 |
| 寻址 | 无 | **7-bit 地址** | 片选 CS |
| 双工 | 全双工 | **半双工**（同一根 SDA） | 全双工 |
| 速度 | 115200 bps | 100k/400k bps | 数十 MHz |
| 设备数 | 1 对 1 | **1 对多**（同一总线挂多个设备） | 1 对多（每设备一根 CS） |

### 3.2 常见问题

- **I2C 为什么需要上拉电阻？** 设备只能拉低不能拉高，上拉电阻负责恢复高电平，同时防止多设备输出冲突。
- **Start 和 Stop 条件分别是什么？** Start = SCL 高时 SDA 高→低；Stop = SCL 高时 SDA 低→高。
- **读寄存器为什么要 Restart？** 先写寄存器地址告诉 Slave 读哪里，然后 Restart 切换为读模式。
