# 20-HardwareProtocol: 硬件协议

> 嵌入式工程师的"语言"——你得看得懂时序图，能配置寄存器让外设跑起来。这些协议是芯片和外面世界沟通的唯一方式。

---

## 学习路线（按难度递增）

```
UART（最简单，2 根线，异步）
  │
  ├──→ I2C（2 根线，同步，有地址）
  │
  ├──→ GPIO（最基础，输入/输出/中断）
  │
  └──→ I2S（3 根线，音频专用）
        │
        └──→ PDM（2 根线，麦克风专用）
```

**为什么先学 UART？** 因为它最简单——没有时钟、没有地址、没有复杂的帧格式。搞懂 UART，后面的协议就都通了。
