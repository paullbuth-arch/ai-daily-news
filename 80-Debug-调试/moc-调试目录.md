## 调试心法

1. **先复现**：不能稳定复现的 bug 几乎没法修
2. **二分法**：注释掉一半代码，确定 bug 在哪一半
3. **一次只改一个变量**：改多个东西就不知道哪个是真正的原因
4. **记录**：把排查过程写进 [[95-Bugs-踩坑日志/moc-踩坑日志目录]]，下次遇到类似的不用重来
