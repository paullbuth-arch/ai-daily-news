# 逻辑分析仪与示波器

**一句话结论（20% 核心）**：逻辑分析仪看数字信号（0/1 的电平变化），示波器看模拟信号（电压波形）。通信协议调试（UART/I2C/SPI）用逻辑分析仪，信号质量（时钟抖动、电源噪声）用示波器。

---

## 第一层：核心认知（必须先看懂）

### 1.1 费曼类比：录音笔 vs 摄像机

- **逻辑分析仪** = 录音笔：只记录声音有没有（0/1），不关心声音大小，但能记录很长时间
- **示波器** = 摄像机：记录完整的画面细节（波形），能看到信号质量，但记录时间短

### 1.2 逻辑分析仪 vs 示波器

| | 逻辑分析仪 | 示波器 |
|---|---|---|
| 看什么 | 数字信号（0/1） | 模拟信号（电压波形） |
| 通道数 | 8-34 通道 | 1-4 通道 |
| 典型用途 | 解码 UART/I2C/SPI 协议 | 检查时钟抖动、电源纹波、信号完整性 |
| 价格 | 便宜（几十到几百元） | 贵（几千到几万元） |
| 采样率 | 100M-1G samples/s | 100M-5G samples/s |

### 1.3 如果只记得一件事

> 逻辑分析仪查协议通信（UART/I2C/SPI 数据对不对），示波器查信号质量（时钟稳不稳、电源噪声大不大）。嵌入式开发 80% 的时候用逻辑分析仪就够了。

## 第二层：实战理解

### 2.1 逻辑分析仪解码 I2C

```
连接:
  CH0 → SCL
  CH1 → SDA
  GND → GND

设置:
  采样率: 2 MHz（≥ 4 倍 I2C 速率）
  触发: SDA 下降沿（Start 条件）

解码结果:
  [S] 0x72 + W [A] 0x10 [A] 0x03 [A] [P]
   │     │   │   │    │   │    │   │   │
   Start 地址  ACK 寄存器 ACK 数据 ACK Stop
```

### 2.2 示波器检查时钟抖动

```bash
# 典型场景：I2C 通信不稳定，怀疑时钟有问题
# 示波器探头接 SCL
# 看到: 时钟边沿有毛刺、上升沿太慢（上拉电阻太大）
# 解决: 换小上拉电阻（4.7kΩ → 2.2kΩ）
```

### 2.3 常见坑

| 问题 | 现象 | 根因 |
|------|------|------|
| 采样率不够 | 解码结果不完整 | 采样率 < 4 倍信号频率，漏掉 bit |
| 地线没接 | 信号全是噪声 | 逻辑分析仪和被测设备必须共地 |
| 触发条件设错 | 抓不到想要的波形 | 触发条件不对，波形没被捕获 |

### 2.4 在 reGlasses 项目中怎么用

WQ7036AX 和 V881 之间的 UART 通信如果出问题（数据乱码、收不到数据），用逻辑分析仪夹在 TX/RX 上抓波形，直接看波特率对不对、数据对不对。I2C 通信问题（ELM2713 不响应）同样用逻辑分析仪看。
