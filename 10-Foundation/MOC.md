# 10-Foundation: C 语言 / OS / 计算机组成

> 嵌入式开发的地基。这三个领域的关系就像：**计算机组成**告诉你"芯片里面有什么"，**C 语言**告诉你"怎么指挥芯片干活"，**OS 概念**告诉你"怎么让芯片同时干多件事"。

---

## 学习路线（按顺序，不要跳）

```
计算机组成 ──→ C 语言核心 ──→ 中断与并发 ──→ RTOS ──→ 内存与 DMA
    │                              │
    └──→ 编译链接启动              └──→ 多核 IPC
                                     └──→ 低功耗 / 可靠性
```

**为什么这个顺序？** 先知道硬件长什么样 → 再学怎么用 C 操控它 → 然后学怎么让多个任务同时跑 → 最后学多核通信和高级主题。
