# 95-Bugs：踩坑日志

> 每次调试遇到有价值的问题，记录在这里。好记性不如烂笔头——三个月后你会感谢现在认真记录的自己。

## 记录模板

```markdown
# [日期] [简述问题]

## 现象
具体表现、错误信息、复现条件

## 排查过程
用了什么工具、看了什么日志、做了什么假设

## 根因
根本原因是什么

## 解决
具体修改了什么

## 预防
下次怎么避免、加什么检查
```

## 已有记录

暂无。开始记录后按时间倒序排列。每条记录应包括：现象→假设→证据→根因→修复→预防。
