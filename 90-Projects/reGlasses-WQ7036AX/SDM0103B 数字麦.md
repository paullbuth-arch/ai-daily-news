# SDM0103B 数字麦

## 一句话理解

SDM0103B 是一颗 **[[PDM 麦克风|PDM]] 接口的 MEMS (Micro-Electro-Mechanical Systems，微机电系统) 数字麦克风**——声波振动内部的微型振膜，芯片直接输出 1-bit 数字信号，不需要外部 ADC (Analog-to-Digital Converter，模数转换器)。

## 为什么学它

reGlasses 有 4 颗 SDM0103B 组成麦克风阵列，是所有音频功能的起点。你得知道它们怎么连线、怎么分组、L/R 怎么选择。

## 阵列布局

```
        ┌──── 眼镜正面 ────┐
        │                  │
   U12  │   [TOF]  [广角]  │  U14
  (左前) │                  │ (右前)
        │                  │
   U13  │                  │  U15
  (左后) │                  │ (右后)
        └──────────────────┘

左声道组 (L1):  U12 + U13, 供电 MIC_BIAS_0 (WQ7036AX B5)
右声道组 (R1):  U14 + U15, 供电 MIC_BIAS_1 (WQ7036AX A7)
```

## 连线详情

```
左声道组:
  DMIC_L1_CLK ──FB5──→ U12.CLK     U12.DATA ─┐
  DMIC_L1_CLK ──FB4──→ U13.CLK     U13.DATA ─┤── FB3 ──→ WQ7036AX
                                              L/R 引脚区分前/后

右声道组:
  DMIC_R1_CLK ──FB8──→ U14.CLK     U14.DATA ─┐
  DMIC_R1_CLK ──FB9──→ U15.CLK     U15.DATA ─┤── FB2 ──→ WQ7036AX
                                              L/R 引脚区分前/后
```

FB (Ferrite Bead，磁珠) 的作用：滤除高频噪声，防止数字信号干扰音频。

## L/R 选择

每组的 2 颗麦通过 **L/R 引脚电平** 区分：
- L/R = GND → 数据在 CLK 上升沿输出 (前)
- L/R = VDD → 数据在 CLK 下降沿输出 (后)

```
CLK:   ╱╲╱╲╱╲╱╲
        ↑  ↓  ↑  ↓
上升沿: U12 数据    U14 数据
下降沿: U13 数据    U15 数据
```

## 供电

| 电源 | 供电对象 | WQ7036AX 引脚 |
|------|----------|--------------|
| MIC_BIAS_0 | U12 + U13 (左侧) | B5 |
| MIC_BIAS_1 | U14 + U15 (右侧) | A7 |

MIC_BIAS 是麦克风的偏置电压 (通常 1.6-3.6V)，由 WQ7036AX 内部提供。

## 数据流

```
声波 → SDM0103B 振膜 → Sigma-Delta 调制器 → PDM 1-bit 输出
                                                    │
                                          CLK + DATA 线
                                                    ↓
                                          WQ7036AX PDM Controller
                                                    │
                                          Decimation Filter
                                                    ↓
                                          PCM 16-bit (见 WQ7036AX 音频管道)
```

#flashcard
问：reGlasses 使用了几颗 SDM0103B？如何分组？
答：4 颗。左声道组 (U12+U13, MIC_BIAS_0) 和右声道组 (U14+U15, MIC_BIAS_1)。每组 2 颗通过 L/R 引脚电平区分前后。

问：一条 PDM DATA 线怎么区分 2 颗麦的数据？
答：L/R=GND 的麦在 CLK 上升沿输出，L/R=VDD 的麦在下降沿输出。WQ7036AX 分别采样两个边沿即可分离两路数据。
