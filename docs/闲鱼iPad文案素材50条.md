## 使用小贴士

1. **配图建议**：
   - 至少3-5张实拍图（正面、背面、边框、细节、配件）
   - 拍一下关于本机的截图（型号、容量、电池健康）
   - 有条件的话拍个爱思/沙漏验机截图

2. **价格策略**：
   - 标价可以略高于心理预期，留出议价空间
   - 可以写"可小刀"吸引买家
   - 急出的话直接标底价，写"不议价"

3. **提高可信度**：
   - 写明购买渠道（官网/京东/实体店等）
   - 有购买记录/发票最好放上
   - 支持验货宝/面交，让买家放心

4. **回复技巧**：
   - 及时回复消息
   - 耐心回答问题
   - 爽快的买家可以送点小礼物
