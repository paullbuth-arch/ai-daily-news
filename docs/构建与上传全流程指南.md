## 1. 版本选型总览（最重要，先看这里）

本项目 `pubspec.yaml` 约束 `sdk: ">=2.17.0 <3.0.0"`，对应 **Flutter 3.0.0**。各组件版本必须互相兼容，**不要随意升级**，否则会出现 Kotlin 元数据版本不匹配等编译错误。

| 组件 | 实际使用版本 | 选择理由 / 备注 |
|---|---|---|
| **Flutter SDK** | 3.0.0 (stable, Dart 2.17.0) | 匹配项目 `pubspec.yaml` 的 SDK 约束 |
| **JDK** | Temurin 17.0.13 | AGP 7.1.2 要求 JDK 11+，17 是 LTS；JDK 20 会导致 AGP 报错 |
| **Android Gradle Plugin (AGP)** | 7.1.2 | 项目 `android/build.gradle` 原有配置，保留不动 |
| **Gradle** | 7.4 (wrapper) | AGP 7.1.2 兼容 Gradle 7.2~7.4；用 wrapper 自动下载 |
| **Kotlin** | 1.7.10 | 项目 `android/build.gradle` 原有配置，保留不动 |
| **Android compileSdk** | 33 | 项目 `android/app/build.gradle` 原有配置 |
| **Android build-tools** | 33.0.0（额外会自动装 30.0.3） | 匹配 compileSdk 33 |
| **Android platform-tools** | 37.0.0 | 最新版即可，含 adb |
| **Android platforms** | android-33 | 匹配 compileSdk 33 |

> **兼容性矩阵核心**：`JDK17 + AGP7.1.2 + Gradle7.4 + Kotlin1.7.10 + compileSdk33`。这套组合已实测可成功构建。

## 2. 第一步：安装 JDK 17

项目的沙箱环境预装了 SDKMAN（`~/.sdkman`），用它装 JDK 最省心。**不要用预装的 JDK 20**，AGP 7.1.2 不支持。

```bash
# 初始化 SDKMAN（如果 ~/.sdkman 已存在可跳过）
source ~/.sdkman/bin/sdkman-init.sh

# 安装 Temurin JDK 17（Eclipse Adoptium 的 LTS 版本）
sdk install java 17.0.13-tem

# 验证
~/.sdkman/candidates/java/17.0.13-tem/bin/java -version
# 期望输出：openjdk version "17.0.13" 2024-10-15
```

如果你在自己的机器上没有 SDKMAN，先装它：

```bash
curl -s "https://get.sdkman.io" | bash
source ~/.sdkman/bin/sdkman-init.sh
```

或者直接从 [Adoptium 官网](https://adoptium.net/temurin/releases/?version=17) 下载 JDK 17 压缩包解压，效果一样。

## 3. 第二步：安装 Flutter SDK

本项目必须用 **Flutter 3.0.0**（对应 Dart 2.17.0），因为 `pubspec.yaml` 写了 `sdk: ">=2.17.0 <3.0.0"`，更高版本的 Flutter 自带 Dart 3.x 会被这个约束拒绝。

```bash
# 方式一：git clone 指定版本（推荐，可精确控制）
git clone -b 3.0.0 https://github.com/flutter/flutter.git /opt/flutter
export PATH="/opt/flutter/bin:$PATH"

# 方式二：如果已装别的版本，切到 3.0.0
cd /opt/flutter
git checkout 3.0.0

# 验证
flutter --version
# 期望输出：Flutter 3.0.0 • channel stable ... Dart version 2.17.0
```

> 如果你的项目可以放宽 SDK 约束（把 `<3.0.0` 改成 `<4.0.0`），也可以用更新的 Flutter，但需要同步升级 AGP/Kotlin，改动较大。**新手建议严格按 3.0.0 来**。

## 4. 第三步：安装 Android SDK（commandline-tools + 组件）

沙箱环境没有预装 Android SDK，需要手动装。核心是先装 **commandline-tools**，再用它里面的 `sdkmanager` 装其他组件。

### 4.1 下载并解压 cmdline-tools

```bash
mkdir -p /opt/android-sdk/cmdline-tools
cd /tmp
# 下载 Android cmdline-tools（官方地址，约 120MB）
curl -sL -o cmdline-tools.zip "https://dl.google.com/android/repository/commandlinetools-linux-9477386_latest.zip"
# 解压后必须重命名为 latest，否则 sdkmanager 找不到
unzip -q cmdline-tools.zip -d /opt/android-sdk/cmdline-tools
mv /opt/android-sdk/cmdline-tools/cmdline-tools /opt/android-sdk/cmdline-tools/latest

# 验证
ls /opt/android-sdk/cmdline-tools/latest/bin/
# 应看到 sdkmanager、avdmanager 等
```

> **关键**：解压后的目录名必须是 `latest`，即 `/opt/android-sdk/cmdline-tools/latest/bin/sdkmanager`。如果直接放在 `cmdline-tools/bin/`，sdkmanager 会报错找不到自己的根目录。

### 4.2 安装 SDK 组件

```bash
export JAVA_HOME=~/.sdkman/candidates/java/17.0.13-tem
export ANDROID_SDK_ROOT=/opt/android-sdk
export ANDROID_HOME=/opt/android-sdk
export PATH="$JAVA_HOME/bin:$ANDROID_SDK_ROOT/cmdline-tools/latest/bin:$PATH"

# 1. 接受所有 license（必须，否则安装会卡在确认）
yes | sdkmanager --licenses

# 2. 安装三大组件
sdkmanager "platform-tools" "platforms;android-33" "build-tools;33.0.0"

# 3. 验证已安装
sdkmanager --list_installed
# 应看到：
#   build-tools;33.0.0
#   platform-tools
#   platforms;android-33
```

> 构建时 Gradle 可能还会自动补装 `build-tools;30.0.3`，这是正常的（某些 AGP 内部任务需要），让它自动装即可。

### 4.3 把 SDK 路径告诉 Flutter

```bash
flutter config --android-sdk /opt/android-sdk
flutter doctor -v
# 期望：[✓] Android toolchain（不再是 ✗ Unable to locate Android SDK）
```

## 6. 第五步：重建不完整的 android 目录

**这是本项目最大的坑**：你给我的源代码压缩包里 `android/` 目录严重不完整——缺少 `AndroidManifest.xml`、`settings.gradle`、`gradle-wrapper`、`MainActivity.kt`、`res/` 资源等。这正是 AI 报 `Failed host lookup`（DNS 解析失败）的根本原因：**没有 AndroidManifest 就没有 INTERNET 权限，release 包无法联网**。

### 6.1 用 flutter create 生成模板

```bash
cd /tmp
rm -rf tpl
# --org 决定包名（com.ipadboss），--project-name 必须与 pubspec.yaml 的 name 一致
flutter create --platforms=android --org com.ipadboss --project-name ipad_boss_app tpl
```

### 6.2 把缺失文件复制到项目

项目原有的 `android/app/build.gradle`（含签名配置）和 `android/build.gradle`（AGP+kotlin 版本）**要保留**，只补缺失的：

```bash
cd /path/to/ipad_boss_app   # 你的项目根目录

# 复制缺失的根级文件（cp -n = 不覆盖已存在的）
cp -n /tmp/tpl/android/gradle.properties android/
cp -n /tmp/tpl/android/settings.gradle android/
cp -n /tmp/tpl/android/gradlew android/
cp -n /tmp/tpl/android/gradlew.bat android/
mkdir -p android/gradle/wrapper
cp -n /tmp/tpl/android/gradle/wrapper/gradle-wrapper.jar android/gradle/wrapper/
cp -n /tmp/tpl/android/gradle/wrapper/gradle-wrapper.properties android/gradle/wrapper/

# app 源码与资源（完整复制 src 目录，含 AndroidManifest、MainActivity、res）
rm -rf android/app/src
cp -r /tmp/tpl/android/app/src android/app/src
```

### 6.3 生成 local.properties

Flutter 构建靠这个文件找 SDK 和 Flutter 路径：

```bash
cat > android/local.properties << 'EOF'
sdk.dir=/opt/android-sdk
flutter.sdk=/opt/flutter
flutter.versionCode=1
flutter.versionName=1.0.0
EOF
```

### 6.4 修改 AndroidManifest.xml 加网络权限

打开 `android/app/src/main/AndroidManifest.xml`，在 `<manifest>` 标签下、`<application>` 标签上加上权限（这是 AI 能联网的关键）：

```xml
<manifest xmlns:android="http://schemas.android.com/apk/res/android"
    package="com.ipadboss.ipad_boss_app">
    <!-- 网络权限：AI(DeepSeek)调用必需 -->
    <uses-permission android:name="android.permission.INTERNET"/>
    <uses-permission android:name="android.permission.ACCESS_NETWORK_STATE"/>
    <!-- 相册写入：Android9及以下需要；Android10+走MediaStore无需此权限 -->
    <uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE" android:maxSdkVersion="28"/>
    <uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" android:maxSdkVersion="32"/>
    <!-- 相机：扫码收货拍照 -->
    <uses-permission android:name="android.permission.CAMERA"/>

    <application
        android:label="机掌柜"
        android:name="${applicationName}"
        android:icon="@mipmap/ic_launcher"
        android:requestLegacyExternalStorage="true">
        ...
    </application>
</manifest>
```

> ⚠️ **注意**：模板生成的 debug 版 AndroidManifest 自带 INTERNET 权限，但 **main 版没有**。release 构建用的是 main 版，所以必须在 main 里加。这是"debug 能联网、release 不能联网"的典型坑。

## 9. 第九步：上传到 gofile.io 并获取下载链接

Gofile 是免费临时云存储，无需注册。流程：**先获取可用服务器，再 POST 上传文件**。

### 9.1 获取可用上传服务器

```bash
curl -s "https://api.gofile.io/servers"
# 返回 JSON，里面有 servers 列表，挑一个 name，比如 store-eu-par-4
```

### 9.2 上传文件

```bash
# 上传 APK
curl -s -X POST "https://store-eu-par-4.gofile.io/contents/uploadfile" \
  -F "file=@机掌柜_v1.0.0_release.apk"

# 上传源代码 zip
curl -s -X POST "https://store-eu-par-4.gofile.io/contents/uploadfile" \
  -F "file=@ipad_boss_app_source.zip"
```

返回的 JSON 里有 `downloadPage` 字段，就是下载链接：

```json
{
  "status": "ok",
  "data": {
    "downloadPage": "https://gofile.io/d/UbEX1F",
    "name": "机掌柜_v1.0.0_release.apk",
    "size": 20098369,
    ...
  }
}
```

### 9.3 验证链接可访问

```bash
curl -sL -o /dev/null -w "HTTP %{http_code}\n" "https://gofile.io/d/UbEX1F"
# 期望：HTTP 200
```

> **批量上传技巧**：如果想把多个文件放同一个分享链接下，先上传第一个文件拿到 `parentFolder`（或 `code`），后续上传时加参数 `-F "folderId=<parentFolder>"` 即可。本次两个文件分开上传了，所以有两个独立链接。

## 常见报错与解决方案（踩坑记录）

### ❌ 报错 1：`Failed host lookup: 'api.deepseek.com'`（AI 调用失败）

**根因**：`android/app/src/main/AndroidManifest.xml` 缺失或没有 INTERNET 权限。
**解决**：按本文第 6.4 节在 main manifest 里加 `<uses-permission android:name="android.permission.INTERNET"/>`。debug manifest 自带权限但 release 不带，必须加到 main。

### ❌ 报错 2：`Could not compile initialization script '/root/.gradle/init.gradle'`

```
Unexpected input: '{' @ line 1, column 13.
allprojects {
```

**根因**：SDKMAN 装的 gradle 注入了一个全局 `~/.gradle/init.gradle`，里面有拼写错误（`mavelCentral` 应为 `mavenCentral`）。
**解决**：修正 `/root/.gradle/init.gradle`：

```gradle
allprojects {
    repositories {
        maven { url 'https://mirrors.tencent.com/nexus/repository/maven-public/' }
        mavenCentral()
        google()
    }
}
```

> 如果不需要腾讯镜像，直接删掉这个文件也行：`rm /root/.gradle/init.gradle`。

### ❌ 报错 3：Kotlin 元数据版本不匹配（一大堆 `incompatible version of Kotlin`）

```
Module was compiled with an incompatible version of Kotlin. The binary version of its metadata is 1.7.1, expected version is 1.5.1.
```

**根因**：JDK 版本过高（用了 JDK 20），导致 AGP 7.1.2 的 Kotlin 编译器版本对不上。
**解决**：换 JDK 17。`sdk install java 17.0.13-tem` 并把 `JAVA_HOME` 指向它。**这些 warning 不影响构建成功**，只要不是 error 就行。

### ❌ 报错 4：`Unable to locate Android SDK`

**根因**：Flutter 不知道 Android SDK 装在哪。
**解决**：`flutter config --android-sdk /opt/android-sdk`，并确认 `ANDROID_SDK_ROOT` 环境变量已设置。

### ❌ 报错 5：`sdkmanager` 找不到自己的根目录

**根因**：cmdline-tools 解压后目录结构不对。
**解决**：必须是 `/opt/android-sdk/cmdline-tools/latest/bin/sdkmanager`，中间那一层目录必须叫 `latest`（见第 4.1 节）。

### ❌ 报错 6：`The name 'RenderRepaintBoundary' isn't a type`

**根因**：用了 `RepaintBoundary` 截图但没 import `rendering.dart`。
**解决**：`import 'package:flutter/rendering.dart';`

### ❌ 报错 7：license 未接受导致安装卡住

**解决**：`yes | sdkmanager --licenses` 一次性接受所有 license。

### ❌ 报错 8：toast 黑框看不见字

**根因**：`SnackBar` 用 `Colors.black87` 背景，应用本身是深色主题（`0xFF0B0F1A`），黑底黑字。
**解决**：改用高对比度配色（卡片色背景 + 品牌色边框 + 清晰文字）。

## 一键脚本（可复用）

把以下脚本存为 `build_and_upload.sh`，下次构建直接跑：

```bash
#!/bin/bash
set -e

# ===== 环境变量 =====
export JAVA_HOME=~/.sdkman/candidates/java/17.0.13-tem
export ANDROID_SDK_ROOT=/opt/android-sdk
export ANDROID_HOME=/opt/android-sdk
export PATH="$JAVA_HOME/bin:$ANDROID_SDK_ROOT/cmdline-tools/latest/bin:$PATH"

PROJECT_DIR="/workspace/source/ipad_boss_app"
OUTPUT_DIR="/workspace/output"
mkdir -p "$OUTPUT_DIR"

cd "$PROJECT_DIR"

# ===== 1. 拉依赖 =====
echo ">>> flutter pub get"
flutter pub get

# ===== 2. 静态检查 =====
echo ">>> flutter analyze"
flutter analyze || true   # info 级提示不阻断

# ===== 3. 单元测试 =====
echo ">>> flutter test"
flutter test

# ===== 4. 构建 release APK =====
echo ">>> flutter build apk --release"
flutter build apk --release

# ===== 5. 复制 APK 到输出目录 =====
cp build/app/outputs/flutter-apk/app-release.apk "$OUTPUT_DIR/机掌柜_release.apk"
echo ">>> APK: $OUTPUT_DIR/机掌柜_release.apk"

# ===== 6. 打包源代码 =====
rm -rf build .dart_tool .flutter-dependencies android/local.properties
cd /workspace/source
zip -rq "$OUTPUT_DIR/ipad_boss_app_source.zip" ipad_boss_app \
  -x "*/build/*" "*/.dart_tool/*" "*.iml"
echo ">>> 源码: $OUTPUT_DIR/ipad_boss_app_source.zip"

# ===== 7. 上传 gofile =====
SERVER="store-eu-par-4"
echo ">>> 上传到 gofile ($SERVER)"
for f in "$OUTPUT_DIR/机掌柜_release.apk" "$OUTPUT_DIR/ipad_boss_app_source.zip"; do
  RESP=$(curl -s -X POST "https://$SERVER.gofile.io/contents/uploadfile" -F "file=@$f")
  LINK=$(echo "$RESP" | grep -o '"downloadPage":"[^"]*"' | cut -d'"' -f4)
  echo "  $(basename "$f") -> $LINK"
done

echo ">>> 全部完成"
```

使用：

```bash
chmod +x build_and_upload.sh
./build_and_upload.sh
```
