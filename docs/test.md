## 一、经营日报优化方案

**当前问题**：只有今日数字 + 一段AI套话，没有对比、没有重点、看完不知道该干啥。

### 优化1：增加周环比/月环比对比

顶部数据卡片从"4个数字"变成"带趋势的对比"：

```
┌─────────────────────────────────────────┐
│  📊 今日数据        更新于 14:30        │
├──────────┬──────────┬──────────┬──────────┤
│  GMV     │  毛利    │  订单数  │  转化率 │
│ ¥12,680  │ ¥2,340   │   8单    │  62%   │
│ ↑12.3%   │ ↑8.5%    │  +2单    │  ↓3.1% │
│  周环比   │  周环比   │  周环比   │ 周环比  │
└──────────┴──────────┴──────────┴──────────┘
```

数据来源：你的订单历史记录，计算近7天/30天平均值做对比。

### 优化2：结构化AI输出，不要一大段文字

把AI输出拆成3个卡片，一眼找到重点：

```
┌─────────────────────────────────┐
│  ✅ 今日亮点                     │
│  • Pro 11寸系列卖了3台，表现超预期 │
│  • 毛利率18.5%，高于上周均值      │

│  • 今日0单新品上架，注意补货节奏   │

┌─────────────────────────────────┐

│  2. 补充 Pro 12.9 256G 库存       │
```

实现方式：改 [AiService.dailyReport](file:///d:/V881/padtest/ipad_boss_app/lib/ai_service.dart#L303-L313) 的system prompt，让AI用固定格式输出（带emoji标记），前端按行解析后分到3个卡片里。

## 二、采购决策优化方案

**当前问题**：手动输成本、数据零散、AI结论太笼统。

### 优化1：选型号后自动填充3个参考价

不用你手动输成本，选完型号直接显示：

```
┌─────────────────────────────────┐
│  iPad Pro 11 2022 128G          │
│                                 │
│  你的历史采购均价  ¥3,850        │
│  今日华强北批发价  ¥4,100  ↑1.2% │
│  你的历史平均售价  ¥4,580        │
│  近30天销量      5台             │
└─────────────────────────────────┘
```

数据来源：

- 历史采购均价 → 你的 [Device](file:///d:/V881/padtest/ipad_boss_app/lib/models.dart#L5-L139) 表中同型号的 `purchaseCost` 均值
- 今日批发价 → [getMarketPrice](file:///d:/V881/padtest/ipad_boss_app/lib/storage.dart#L506-L511)
- 历史平均售价 → 已售出订单的同型号均价

### 优化2：真实利润拆解（不是粗略差价）

```
┌─────────────────────────────────┐
│  💰 预估单台利润（按 ¥3,900 拿货）│
│                                 │
│  预计售价        ¥4,580         │
│  拿货成本       -¥3,900         │
│  维修成本预估    -¥80           │
│  平台佣金预估    -¥137          │
│  物流+包装      -¥45            │
│  售后预留       -¥60            │
│  ─────────────────────          │
│  预估净利        ¥358（7.8%）   │
│  预计周转天数    26天            │
└─────────────────────────────────┘
```

维修/佣金/物流/售后的成本都可以从你的历史订单数据里算出同型号的平均值。

### 优化3：风险评分（本地计算，不用等AI）

用几个维度打个分，一目了然：

```
┌─────────────────────────────────┐
│  🎯 综合评分：72分（谨慎收）      │
│                                 │
│  利润空间      ████████░░  80分  │
│  周转速度      ██████░░░░  60分  │
│  库存压力      █████░░░░░  50分  │
│  价格趋势      ████████░░  80分  │
└─────────────────────────────────┘
```

4个维度各占权重，综合评分自动得出结论，不用每次调AI。AI可以作为补充解释。

### 优化4：一键对标"历史最佳采购价"

```
💡 历史最佳：该型号你曾以 ¥3,650 收过一台（3个月前，95新）
   当前报价 ¥3,900 比历史最佳贵 ¥250
```

不是只看一个型号，而是基于近30天销量 + 当前库存，给出"本周该补什么"：

```
┌─────────────────────────────────┐

│     库存2台 / 月销8台 → 补3-4台  │

│  ② iPad Air 5 64G               │
```
