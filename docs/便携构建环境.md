# 开发环境下载说明

项目不提交 `dev_env`。Flutter SDK、Android SDK、JDK 加起来体积很大，完整打包约 8GB，不适合放进 GitHub 仓库，也不建议作为常规 Release 附件。

推荐做法是：新电脑从官方渠道下载 SDK，统一放到项目同级的 `dev_env`。

```text
workspace/
  dev_env/
    android-sdk/
    flutter/
    jdk-17.0.13+11/
  ipad_boss_app/
```

## 下载入口

Flutter 3.29.0 Windows SDK：

```text
https://storage.googleapis.com/flutter_infra_release/releases/stable/windows/flutter_windows_3.29.0-stable.zip
```

Flutter 官方归档页：

```text
https://docs.flutter.dev/install/archive
```

Temurin JDK 17 Windows x64：

```text
https://adoptium.net/temurin/releases/?version=17&os=windows&arch=x64&package=jdk
```

Android Command-line tools：

```text
https://developer.android.com/studio
```

Android `sdkmanager` 说明：

```text
https://developer.android.com/tools/sdkmanager
```

## Android SDK 组件

解压 Android Command-line tools 后，确保存在：

```text
..\dev_env\android-sdk\cmdline-tools\latest\bin\sdkmanager.bat
```

然后在项目根目录执行：

```powershell
$Jdk = Get-ChildItem ..\dev_env -Directory -Filter "jdk*" | Select-Object -First 1
$env:JAVA_HOME = $Jdk.FullName
$env:ANDROID_HOME = (Resolve-Path ..\dev_env\android-sdk).Path
$env:ANDROID_SDK_ROOT = $env:ANDROID_HOME
$env:Path = "$env:JAVA_HOME\bin;$env:ANDROID_HOME\cmdline-tools\latest\bin;$env:ANDROID_HOME\platform-tools;$env:Path"

sdkmanager.bat --licenses
sdkmanager.bat "platform-tools" "platforms;android-35" "build-tools;35.0.0" "ndk;27.0.12077973"
```

## 构建

检查环境：

```powershell
powershell -ExecutionPolicy Bypass -File tools\check_build_env.ps1
```

构建 APK：

```powershell
powershell -ExecutionPolicy Bypass -File tools\build_apk.ps1 -SkipPubGet
```

完整说明见根目录 [BUILD_APK.md](../BUILD_APK.md)。
