# 闲鱼监控与自动采集系统设计方案

## 1. 需求概述

在现有"机掌柜"ERP系统基础上，新增**闲鱼（Xianyu）货源监控模块**，实现：

| 功能 | 描述 |
|------|------|
| **自动监控** | 定时扫描闲鱼最新发布的 iPad 商品，按关键词、价格区间、成色等条件筛选 |
| **智能过滤** | 自动识别高性价比商品（低于市场均价、个人卖家、信誉良好等） |
| **实时推送** | 命中条件的商品即时推送到 App 内，并支持通知提醒 |
| **一键归档** | 推送的商品可直接生成采购意向单，快速录入库存系统 |
| **价格追踪** | 持续追踪已关注商品的价格变动，降价时触发提醒 |

### 4.2 核心流程

```python
# tools/xianyu_scraper/main.py（简化示意）

import asyncio
from scraper.browser import XianyuBrowser
from scraper.search import SearchExecutor
from scraper.filter import ListingFilter
from storage.sqlite_store import SqliteStore
from notifier.push import PushNotifier
from config import SCRAPER_TASKS

async def run_task(task: ScraperTask):
    """执行单个监控任务"""
    browser = XianyuBrowser()
    store = SqliteStore()
    
    try:
        # 1. 登录（使用保存的Cookie）
        await browser.login_with_cookie("cookies/cookie_default.json")
        
        # 2. 执行搜索
        results = await SearchExecutor(browser).search(
            keyword=task.keyword,
            price_range=(task.minPrice, task.maxPrice),
            sort=task.sortBy
        )
        
        # 3. 过滤与评分
        filtered = ListingFilter(results) \
            .by_personal(task.onlyPersonal) \
            .by_price(task.minPrice, task.maxPrice) \
            .by_location(task.locations) \
            .score()  # AI 性价比评分
        
        # 4. 与上次结果对比，找出新发布的
        new_listings = store.diff(filtered)
        
        # 5. 推送到 App
        if new_listings:
            await PushNotifier().send(new_listings, task.name)
            store.save(new_listings)
            
    finally:
        await browser.close()

async def main_loop():
    """定时轮询所有任务"""
    while True:
        for task in SCRAPER_TASKS:
            if task.isEnabled:
                await run_task(task)
        await asyncio.sleep(60)  # 每分钟检查一次任务调度

if __name__ == "__main__":
    asyncio.run(main_loop())
```

### 4.3 搜索模块关键实现

```python
# tools/xianyu_scraper/scraper/search.py

class SearchExecutor:
    """闲鱼搜索执行器"""
    
    SEARCH_URL = "https://www.goofish.com/search?q={keyword}"
    
    async def search(self, keyword: str, price_range: tuple, sort: str) -> list[dict]:
        """
        执行搜索并解析结果
        
        注意：闲鱼PC搜索返回的是服务端渲染+客户端JS混合页面，
        需用 Playwright 执行 JS 后提取 DOM。
        """
        page = await self.browser.new_page()
        
        # 构造搜索URL（含价格筛选参数）
        url = self._build_search_url(keyword, price_range, sort)
        await page.goto(url, wait_until="networkidle")
        await asyncio.sleep(3)  # 等待 JS 渲染
        
        # 提取商品列表
        items = await page.evaluate("""
            () => {
                // 根据实际页面结构调整选择器
                const cards = document.querySelectorAll('[class*="item"], .search-item, [data-item-id]');
                return Array.from(cards).map(card => ({
                    id: card.dataset.itemId || '',
                    title: card.querySelector('h1, .title, [class*="title"]')?.innerText?.trim() || '',
                    priceText: card.querySelector('[class*="price"]')?.innerText?.trim() || '',
                    // ... 其他字段
                }));
            }
        """)
        
        await page.close()
        return [self._normalize(item) for item in items if item.get('id')]
    
    def _build_search_url(self, keyword, price_range, sort):
        params = {'q': keyword}
        if price_range[0] > 0:
            params['startPrice'] = price_range[0] // 100  # 分转元
        if price_range[1] > 0:
            params['endPrice'] = price_range[1] // 100
        # sort 映射...
        return f"https://www.goofish.com/search?{urlencode(params)}"
```

```dart
class XianyuListingsPage extends StatefulWidget {

  State<XianyuListingsPage> createState() => _XianyuListingsPageState();

class _XianyuListingsPageState extends State<XianyuListingsPage> {
  List<XianyuListing> _listings = [];
  String _filterStatus = 'new';  // new / all / interested

  @override
  void initState() {
    super.initState();
    _loadListings();
    _setupWebSocket();  // 实时接收推送
  }

  Future<void> _loadListings() async {
    final data = await ApiService.get('/api/xianyu/listings?status=$_filterStatus');
    setState(() => _listings = (data['list'] as List)
        .map((j) => XianyuListing.fromJson(j))
        .toList());
  }

  void _setupWebSocket() {
    // WebSocket 监听新货源推送
    ApiService.onWebSocket('xianyu:new', (listingJson) {
      final listing = XianyuListing.fromJson(listingJson);
      setState(() => _listings.insert(0, listing));
      // 本地通知
      NotificationService.show(
        title: '发现高性价比货源',
        body: '${listing.title} - ¥${listing.price / 100}',
      );
    });
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: Text('闲鱼货源监控')),
      body: ListView.builder(
        itemCount: _listings.length,
        itemBuilder: (ctx, i) => XianyuListingCard(
          listing: _listings[i],
          onTap: () => _openDetail(_listings[i]),
          onInterested: () => _markInterested(_listings[i]),
          onToDevice: () => _convertToDevice(_listings[i]),
        ),
      ),
    );
  }

  /// 一键转为库存设备
  Future<void> _convertToDevice(XianyuListing listing) async {
    final device = Device(
      id: DateTime.now().millisecondsSinceEpoch.toString(),
      serial: '',  // 待补充
      model: listing.modelHint,
      capacity: '',  // 待从标题提取
      color: '',
      network: '',
      condition: listing.conditionHint,
      purchaseCost: listing.price,  // 以售价作为预估采购成本
      purchaseChannel: '闲鱼 - ${listing.sellerName}',
      purchaseDate: DateTime.now().toIso8601String().split('T')[0],
      status: 'in_stock',
      description: listing.description,
      createdAt: DateTime.now().toIso8601String(),
    );
    await Storage().saveDevice(device);
    // 标记为已采购
    await ApiService.post('/api/xianyu/listings/${listing.id}/status', 
        body: {'status': 'purchased'});
  }
}
```

## 7. 通知推送方案

| 推送渠道 | 触发条件 | 实现方式 |
|----------|----------|----------|
| **App 内实时** | 新货源命中条件 | WebSocket 连接后端 |
| **系统通知** | 高性价比货源（score > 80） | Flutter Local Notifications |
| **微信/钉钉** | 用户配置的关键字命中 | 调用后端 Webhook 接口 |
| **短信** | 超低价紧急货源 | 后端集成短信API（阿里云/腾讯云） |

## 8. 风险与应对

| 风险 | 等级 | 应对措施 |
|------|------|----------|
| 闲鱼Cookie过期 | ⭐ 高 | 每周提醒用户重新登录一次 |
| 账号被封/风控 | ⭐⭐ 中 | 多账号轮询；控制请求频率；模拟真人行为 |
| 搜索结果不准确 | ⭐⭐ 中 | AI提取型号/成色后人工二次确认 |
| 商品已售出 | ⭐ 低 | 抓取时检测"已售出"标记；详情页二次确认 |
| 数据量过大 | ⭐ 低 | 自动清理7天前的未标记数据；分页加载 |
