# GPIO 配置

**一句话结论（20% 核心）**：GPIO 是芯片上最基础的引脚——设为"输入"读按键状态，设为"输出"控制 LED 亮灭。所有复杂协议（UART/I2C/I2S）的引脚都是从 GPIO "复用"过来的。

---

## 第一层：核心认知（必须先看懂）

### 1.1 费曼类比：GPIO 就像配电箱的开关

一个 GPIO 引脚就像一个**可以编程控制的开关**：
- 设为**输出**：你可以控制它输出高电平（3.3V）或低电平（0V）——就像合上或拉下电闸
- 设为**输入**：你可以读它现在的电平——就像看电闸是合上还是拉下
- 设为**中断输入**：电平变化时自动通知 CPU——就像电闸上装了报警器

### 1.2 GPIO 的三种模式

| 模式 | 方向 | 干什么 | 例子 |
|---|---|---|---|
| 输出 | CPU→外部 | 控制外部器件 | 点亮 LED、使能电源 |
| 输入 | 外部→CPU | 读取外部状态 | 读按键是否按下 |
| 中断输入 | 外部→CPU | 状态变化时自动通知 | 光传感器检测到佩戴 |

### 1.3 按键为什么需要上拉和防抖？

**上拉电阻**：按键一端接 GPIO，一端接 GND。不按时，引脚通过上拉电阻保持高电平（1）；按下时，引脚被拉到 GND，读到低电平（0）。

```
不按：3.3V → [上拉电阻] → GPIO 引脚（读到 1）
按下：GND → [按键闭合] → GPIO 引脚（读到 0）
```

**防抖**：机械按键按下/松开时，金属弹片会抖动 10-20ms，导致电平快速跳变。软件读到一个变化后，延时 20-50ms 再确认，跳过抖动期。

### 1.4 如果只记得一件事

> GPIO = 输入（读状态）+ 输出（控制器件）+ 中断（变化通知）。按键要上拉 + 防抖。所有外设引脚都是 GPIO 的复用功能。

## 第二层：实战理解

### 2.1 WQ7036AX 的 GPIO API

SDK 中 GPIO 驱动核心 API：

```c
// 设置引脚功能：普通 GPIO 还是复用为 UART/I2C 等
gpio_set_func(pin, GPIO_FUNC_NORMAL_GPIO);

// 设置方向
gpio_set_direction(pin, GPIO_DIR_INPUT);   // 输入（读按键）
gpio_set_direction(pin, GPIO_DIR_OUTPUT);  // 输出（控 LED）

// 读写电平
gpio_set_level(pin, 1);                    // 输出高电平
uint8_t level = gpio_get_level(pin);       // 读输入电平

// 配置上下拉
gpio_set_pull(pin, GPIO_PULL_UP);

// 注册中断
gpio_register_interrupt(pin, GPIO_INT_FALLING, callback, arg);
```

### 2.2 reGlasses GPIO 映射表

**按键（输入，上拉，低电平有效）：**

| 按键 | 引脚 | 功能 | 操作 |
|---|---|---|---|
| KEY_1 | M14 | 功能键 A | 长按 1s=录制，单击=拍照，双击=切镜头 |
| KEY_2 | M5 | 功能键 B | 单击=语音，长按 1s=录音，长按 5s=配网 |
| KEY_3 | N6 | 电源键 | 长按 2s=开关机 |

**LED（输出）：**

| LED | 引脚 | 颜色 | 用途 |
|---|---|---|---|
| LED_R | N10 | 红 | 录制中/警告 |
| LED_G | M10 | 绿 | 开机/正常 |
| LED_B | N11 | 蓝 | 配网/蓝牙 |

**中断输入：**

| 信号 | 引脚 | 来源 | 触发 |
|---|---|---|---|
| LS_INT | M12 | ELM2713 光传感器 | 佩戴检测 |
| CHARGE_INT | M11 | 充电 IC | 充电状态变化 |
| FAULT | E9 | 电源管理 | 故障告警 |

**控制输出：**

| 信号 | 引脚 | 用途 |
|---|---|---|
| PS_EN | J9 | 电源芯片使能 |
| BT-WK-V881 | M13 | 唤醒 V881 |

### 2.3 常见坑

| 问题 | 现象 | 根因 |
|---|---|---|
| 忘配上拉 | 按键不按时电平不确定 | 输入浮空，没有默认电平 |
| 忘防抖 | 按一次触发了多次 | 机械抖动导致多次边沿触发 |
| 复用功能冲突 | 外设不工作 | 两个外设被分配到了同一引脚 |
| 中断忘清标志 | 中断不断触发 | ISR 退出后中断标志位还是挂起的 |
