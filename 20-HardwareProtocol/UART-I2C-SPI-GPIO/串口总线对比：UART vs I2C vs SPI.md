# 串口总线对比：UART vs I2C vs SPI

## 为什么要对比

这三种是嵌入式最常用的串行总线 (Serial Bus)。reGlasses 用了 UART 和 I2C (没用 SPI)，但你得知道**为什么选这个不选那个**。

## 一图看懂

```
UART (2线, 异步, 点对点):
  TX ──────→ RX
  RX ←────── TX

I2C (2线, 同步, 一主多从):
  SCL ──┬──┬──┬──┬──
  SDA ──┼──┼──┼──┼──
       M   S1  S2  S3

SPI (4线, 同步, 全双工):
  SCK  ──→ SCK
  MOSI ──→ MOSI
  MISO ←── MISO
  CS   ──→ CS
```

## 对比表

| 维度 | [[UART 基础\|UART]] | [[I2C 基础\|I2C]] | SPI |
|------|-------|-------|-----|
| **线数** | 2 (TX+RX) | 2 (SDA+SCL) | 4 (MOSI/MISO/SCK/CS) |
| **同步/异步** | **异步** (无时钟线) | 同步 (SCL) | 同步 (SCK) |
| **双工** | 全双工 | 半双工 (共用SDA) | 全双工 |
| **寻址** | 无 (点对点) | **地址 (7/10-bit)** | 片选 (CS) |
| **设备数** | 1 对 1 | 1 对多 (地址区分) | 1 对多 (CS 区分) |
| **速度** | 115200 bps 典型 | 100k/400k/3.4M | **数十 MHz** |
| **复杂度** | 最简单 | 中等 | 较复杂 |
| **上拉电阻** | 不需要 | **需要** | 不需要 |
| **reGlasses 用在哪** | WQ↔V881 (STTP) | ELM2713 + 充电IC | 未使用 |

## 什么时候选哪个？

```
需要长距离、跨芯片通信？
  └→ UART (简单可靠，加 STTP 做校验)

需要连接多个低速传感器？
  └→ I2C (地址寻址，2 根线搞定)

需要高速传输 (Flash、显示屏)？
  └→ SPI (全双工 + 高时钟频率)
```

## reGlasses 为什么选 UART 连 V881 而不是 SPI？

1. UART 足够用：STTP 传输的是控制指令 + 压缩音频，~1Mbps 够用
2. UART 更简单：2 根线，不需要片选，调试方便 (串口助手直接看)
3. SPI 需要 4 根线 + 更高时钟配置，在眼镜紧凑空间里多一根线都是负担

#flashcard
问：UART 和 I2C 最大的区别是什么？
答：UART 是异步通信 (无时钟线，靠约定波特率)，I2C 是同步通信 (有 SCL 时钟线)。UART 是点对点，I2C 支持地址寻址一主多从。

问：reGlasses 为什么不用 SPI 连 V881？
答：UART + STTP 的 ~1Mbps 带宽足够传输控制指令和压缩音频。SPI 虽然更快但需要 4 根线，在眼镜紧凑空间中不值得。
